# 第92讲　一眼看全文：Transformer

> 一面琉璃只交出一个汇合。两面并排，才同时看见三和一。

---

## 导语

位置编码先只算位置 $0$、维度 $2$。偶数下标走正弦，奇数下标走余弦。位置是 $0$ 时，正弦的自变量是 $0$，正弦是 $0$；余弦的自变量是 $0$，余弦是 $1$。所以这一位写成 $(0,1)$。词向量若是 $(1,0)$，加上位置，得到 $(1,1)$。不计算位置 $1$ 的正弦。那不是整数。

自注意力另开一本账，不要和位置的 $(1,1)$ 加在一起。两个位置的查询和键都是 $1$，维度是 $1$，除数是 $1$。打分全是 $1$。权重各是 $\dfrac{1}{2}$。值是 $4$ 和 $2$。每一处的汇合都是 $3$。整行变成 $3$ 和 $3$。

第二面琉璃用同一套权重，值改成 $0$ 和 $2$，汇合是 $1$。两面拼起来是 $3$ 和 $1$。单头的残差把原值加回去：$4+3=7$，$2+3=5$。拼接的 $3$ 和 $1$ 再按第七十八讲除以个数做一次按行：$3$ 与 $1$ 的均值是 $2$，方差是 $1$，得到 $1$ 与 $-1$。这不是把 $7$ 和 $5$ 归一化。若硬把 $7$ 与 $5$ 送进同一套按行，均值是 $6$，离均差已是 $1$ 与 $-1$，结果也是 $1$ 与 $-1$。两本账数字撞车，所以要靠来历分开，不能靠这一对结果分开。

琉璃屏风不是第十一讲的铜镜，也不是第四十五讲盒里的琉璃屑，也不是第二十讲的素屏。屏风是多面同时看同一行。铜镜是一面。屑是碎在格子里的票。素屏是投影用的那一堵。

第九十一讲的 $e^{2}$ 不在本讲重算。那一讲查询来自圈外。本讲的查询来自这一行自己。

三个葡萄品种不用。不下载。种子 $92$ 只抽一张二乘二的小数，不参与手算。脚本不用自动求导的那种库。

这一讲回答六个问题：

1. 位置 $0$ 的两维为什么是 $(0,1)$，不是 $(1,0)$？
2. 值 $4$ 与 $2$、权重各 $\dfrac{1}{2}$，汇合为什么是 $3$？
3. 第二面为什么汇成 $1$，拼接为什么是 $3$ 与 $1$？
4. 残差为什么是 $7$ 与 $5$，而不是只留下 $3$ 与 $3$？
5. $3$ 与 $1$ 的按行结果为什么是 $1$ 与 $-1$？它和 $7$ 与 $5$ 是同一本账吗？
6. 写成一般式，单头那本账要哪两个条件？

## 92.1　自己看自己

第九十一讲已经有查询、键、值。自注意力（self-attention）只改一件事：查询、键、值都从同一行里来。第一个位置用自己的查询，去看这一行全部的键，再按权重把全部的值加起来。第二个位置也这样做。谁也不必先把整段压进一个隐藏状态。

多头是好几面一起做这件事。每一面可以有自己的值，真模型里还有自己的投影，所以打分也可以不同。本讲两面的打分都写成 $1$ 与 $1$，差别先放在值上。种子抽的那张表只说明投影可以不同，不拿来改 $3$ 和 $1$。

这种一层一层、自己看全文的架子，常被称作 Transformer。旁白可以不念这组字母。截至本讲写作时，大模型的一层里仍常能看见自注意力、多头、位置、残差和归一化。位置的具体写法会变。偶数正弦、奇数余弦是 2017 年那篇里的一种。本讲只核位置 $0$。不把某一种位置写成终点。

## 92.2　纸笔：位置零是零和一

维度 $d=2$ 时，只有一对下标。偶数位 $2i$（本讲 $i=0$，所以是第 $0$ 位）用正弦，奇数位用余弦：

$$
\mathrm{PE}(p,2i)=\sin\left(\frac{p}{10000^{2i/d}}\right),\qquad
\mathrm{PE}(p,2i+1)=\cos\left(\frac{p}{10000^{2i/d}}\right).
$$

$p=0$，$d=2$，$i=0$。$10000^{0}=1$。于是

$$
\sin(0/1)=0,\qquad \cos(0/1)=1.
$$

位置向量是 $(0,1)$。词若是 $(1,0)$，相加：

$$
(1,0)+(0,1)=(1,1).
$$

位置是 $0$ 时，除数是多少都不改结果，因为分子已经是 $0$。$10000^{0}=1$，正弦的自变量是 $0/1=0$。所以 $(0,1)$ 不是近似。它是这个公式在这一位上的原样。词 $(1,0)$ 加上去得 $(1,1)$。$(1,1)$ 两个分量的平方和是 $1+1=2$，和位置向量 $(0,1)$ 的平方和 $0+1=1$、词向量的平方和 $1+0=1$ 都不相同。加之前点积是 $0$，加之后自己和自己的点积是 $2$。后面的位置会把正弦、余弦算出不是整数的数。本讲不算。图见 `figs/l092_pos.png`。

点积本身不分谁在前。把 $(1,0)$ 换成 $(0,1)$，点积会变，但那是内容变了，不是「第几位」被写进了式子。位置编码是把第几位加进内容。本讲只加这一次，加完是 $(1,1)$。这本账到此为止，不拿去加下面的 $3$。

## 92.3　纸笔：四与二汇成三

两个位置。查询都是 $1$，键都是 $1$，维度 $d=1$，除数 $\sqrt{1}=1$。打分矩阵每一格都是 $1\times 1=1$。

每一行做软最大。两枚打分相同：

$$
\frac{e}{e+e}=\frac{e}{2e}=\frac{1}{2}.
$$

两行都是 $\dfrac{1}{2}$ 与 $\dfrac{1}{2}$。值是 $4$ 和 $2$。每一处汇合：

$$
\frac{1}{2}\times 4+\frac{1}{2}\times 2=2+1=3.
$$

整行是 $3$ 和 $3$。第九十一讲在权重各一半、值 $4$ 与 $0$ 时，汇合是 $2$。本讲值是 $4$ 与 $2$，$3-2=1$，多出来的 $1$ 就是 $2$ 的一半。$\dfrac{1}{2}\times 4=2$，$\dfrac{1}{2}\times 2=1$，$2+1=3$。不要把两讲的汇合听成同一个数。$4-3=1$，$3-2=1$，汇合离较大的值和离较小的值一样远，因为两枚权重相等。若先把值相加得 $4+2=6$，再除以 $2$，仍是 $3$。漏掉这次除法就停在 $6$，$6-3=3$，多出来的正好又是一份汇合。两个位置都得到 $3$，所以整行是 $3$ 与 $3$，两处之和是 $6$，和没除以前的 $4+2$ 撞上同一个数，可一个是两处汇合相加，一个是两处原值相加。$6\div 2=3$，除完才回到一处的汇合。

第二面值是 $0$ 和 $2$，$\dfrac{1}{2}\times 0+\dfrac{1}{2}\times 2=1$。第一面 $3$，第二面 $1$。两面再平均是 $\dfrac{3+1}{2}=2$，正好是投影 $\left(\dfrac{1}{2},\dfrac{1}{2}\right)$ 投回去的那个 $2$。残差就变成 $4+2=6$ 与 $2+2=4$。只留第一面是 $3$，残差 $7$ 与 $5$；只留第二面是 $1$，残差 $5$ 与 $3$。$7-6=1$，$6-5=1$，大的那一处每把投影从 $(1,0)$ 收到平均、再收到 $(0,1)$，都少 $1$。小的那一处 $5-4=1$，$4-3=1$，同样少 $1$。差始终是 $2$。$7$、$6$、$5$ 的相邻差是 $1$，$5$、$4$、$3$ 的相邻差也是 $1$。$7+5=12$，$6+4=10$，$5+3=8$，三对之和相邻少 $2$，因为两处各少 $1$。拼起来是 $(3,1)$，两维之和 $3+1=4$。位置向量 $(0,1)$ 的平方和是 $1$，词 $(1,0)$ 的平方和是 $1$，相加后 $(1,1)$ 的平方和是 $2$。$1+1=2$，平方和相加等于加之后的平方和，是因为加之前点积是 $0$，交叉项 $2\times 1\times 0=0$。词若是 $(2,0)$，平方和是 $4$，加上 $(0,1)$ 得 $(2,1)$，平方和 $4+1=5$。$5-2=3$，比 $(1,1)$ 的平方和多 $3$，因为内容从 $1$ 换成 $2$，平方从 $1$ 换成 $4$，多了 $3$，位置那一维仍是 $1$。均值 $\dfrac{3+1}{2}=2$，离差都是 $1$，平方和 $1+1=2$，除以 $2$ 得方差 $1$。$\dfrac{3-2}{1}=1$，$\dfrac{1-2}{1}=-1$。第七十八讲是 $1$ 与 $3$，得到 $-1$ 与 $1$。本讲顺序相反，均值都是 $2$，极差都是 $2$。

## 92.4　两面，以及加回去

第二面权重仍各是 $\dfrac{1}{2}$，因为本讲也把它的打分写成 $1$ 与 $1$。值改成 $0$ 和 $2$：

$$
\frac{1}{2}\times 0+\frac{1}{2}\times 2=1.
$$

每一处都得到 $1$。和第一面的 $3$ 拼在一起，是 $(3,1)$。图见 `figs/l092_screen.png`。

这不是「两面都叫 $3$」。也不是把 $3$ 抄两遍。真模型还会用一个投影把拼接的宽度投回原来的宽度。这一节先不设那个投影，手算停在 $(3,1)$。投回原宽的三张表在 92.7 节。

这一节的残差先只做在第一面，也就是单头那本账上。原值还在：

$$
4+3=7,\qquad 2+3=5.
$$

汇合 $3$ 是按别人和自己各取一半得到的新内容。残差说：原来的 $4$ 和 $2$ 不要扔掉。扔掉，就只剩 $3$ 和 $3$。第七十八讲的归一化不作用在 $7$ 和 $5$ 上。这两个数各在一个位置，单独一个数没有标准差可用。若硬把 $7$ 与 $5$ 送进同一套按行，结果也是 $1$ 与 $-1$，所以不能靠这两个数分辨两本账。本讲按行的输入仍是拼接的 $3$ 与 $1$。

拼接 $(3,1)$ 才有两个特征，可以按行，除以个数 $2$，不除以 $2-1$。均值：

$$
\frac{3+1}{2}=2.
$$

方差：

$$
\frac{(3-2)^{2}+(1-2)^{2}}{2}=\frac{1+1}{2}=1.
$$

于是

$$
\frac{3-2}{1}=1,\qquad \frac{1-2}{1}=-1.
$$

第七十八讲是 $1$ 与 $3$，得到 $-1$ 与 $1$。本讲是 $3$ 与 $1$，得到 $1$ 与 $-1$。算法相同，顺序相反。不重算那一讲的水泡。截至本讲写作时，有的层先相加再归一，有的先归一再进自注意力。本讲手算的顺序是：先汇合，单头再相加；拼接的两维单独做这一次按行。不把某一种先后写成唯一。

## 92.5　三本账不要并

| 账 | 输入 | 结果 | 不要并进去的数 |
|---|---|---|---|
| 位置 | 词 $(1,0)$，位置 $(0,1)$ | $(1,1)$ | 不要加上 $3$ |
| 单头 | 值 $4$ 与 $2$，权重各 $\dfrac{1}{2}$ | 汇合 $3$ 与 $3$；残差 $7$ 与 $5$ | 不要说原值消失 |
| 两面 | 第二面值 $0$ 与 $2$ | 汇合 $1$；拼接 $(3,1)$；按行后 $1$ 与 $-1$ | 不要把 $7$、$5$ 送进这一次按行 |

种子 $92$ 的二乘二是另一张抽数，四位小数，不进入这三本账。三本账的结果可以并排看，不能加。位置得到 $(1,1)$，两维之和是 $2$。单头残差是 $7$ 与 $5$，和是 $12$。拼接按行是 $1$ 与 $-1$，和是 $0$。$2$、$12$、$0$ 三个和，没有一个等于另一个。$(1,1)$ 的点积是 $1+1=2$，残差 $7\times 5$ 不是这本账要算的积。按行后的 $1$ 与 $-1$ 相加为 $0$，是因为均值已经减掉。三本账各停在自己的结果上。

## 92.6　一般式：一层里的几行式子

一行有 $n$ 个位置，每个位置是一个 $d_{\text{model}}$ 维向量（读作「模型宽度」），排成 $n$ 行的输入表 $X$。

**加位置。** $X\leftarrow X+P$。$P$ 的第 $p$ 行是 92.2 节的正弦、余弦，位置 $0$ 那行是 $(0,1)$。

**自注意力。** 三张投影 $W^{Q}$、$W^{K}$、$W^{V}$ 读作「查询投影、键投影、值投影」，由训练学出：

$$
Q=XW^{Q},\quad K=XW^{K},\quad V=XW^{V},\qquad
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}\right)V.
$$

$d_k$ 是键的维度。软最大按行做，第 $i$ 行第 $j$ 枚权重是

$$
a_{ij}=\frac{e^{s_{ij}}}{\sum_{m=1}^{n}e^{s_{im}}},\qquad s_{ij}=\frac{\boldsymbol{q}_i\cdot\boldsymbol{k}_j}{\sqrt{d_k}}.
$$

第 $i$ 处的汇合是 $\sum_j a_{ij}\boldsymbol{v}_j$。和第九十一讲的差别：这里 $Q$ 的每一行来自这一行自己。

**多头。** 第 $h$ 面有自己的三张投影，算出 $\text{head}_h$；$H$ 面拼起来，再乘 $W^{O}$ 投回模型宽度：

$$
\mathrm{MultiHead}(X)=\mathrm{Concat}(\text{head}_1,\dots,\text{head}_H)\,W^{O}.
$$

2017 年那篇的基础设置取模型宽度 $512$、$8$ 面、每面 $d_k=64$，$8\times 64=512$。$512\div 8=64$，$512\div 64=8$。$8\times 64=512$。若八面各用 $64$，拼起来正好是模型宽度，投回之前不必先把宽度裁短。$\sqrt{64}=8$，$\sqrt{512}$ 更大，本讲手算不走那两个除数。位置 $0$ 的 $(0,1)$ 加上词 $(1,0)$ 得 $(1,1)$。若词换成 $(2,0)$，得到 $(2,1)$。两个结果的第一维差 $1$，第二维都是 $1$。自注意力若不用位置，对调这两个词只把输出换序；加上 $(0,1)$ 以后，第 $0$ 位一个是 $(1,1)$、一个是 $(2,1)$，不再是彼此换序，因为位置向量不是 $(0,0)$。$(1,1)-(2,1)=(-1,0)$，差全在内容那一维。

汇合 $3$ 加回 $4$ 与 $2$，得到 $7$ 与 $5$。若先把 $7$ 与 $5$ 按行，均值 $6$，结果 $1$ 与 $-1$，和把 $3$ 与 $1$ 按行的结果相同，均值却是 $6$ 不是 $2$。$6-2=4$，差的是加回去的那一截里两处相同的部分。两本账的按行结果撞车，均值没有撞车。本讲按行的输入仍是拼接的 $3$ 与 $1$。

**残差与按行。** 2017 年那篇写成 $\boldsymbol{y}=\mathrm{LN}\big(\boldsymbol{x}+\mathrm{Sublayer}(\boldsymbol{x})\big)$，后来常见的另一种是 $\boldsymbol{y}=\boldsymbol{x}+\mathrm{Sublayer}(\mathrm{LN}(\boldsymbol{x}))$。$\mathrm{LN}$ 就是第七十八讲的按行：一个位置的 $d$ 个特征 $z_1,\dots,z_d$，

$$
\mu=\frac{1}{d}\sum_{j}z_j,\qquad \sigma^2=\frac{1}{d}\sum_j (z_j-\mu)^2,\qquad \hat z_j=\gamma\,\frac{z_j-\mu}{\sqrt{\sigma^2+\varepsilon}}+\beta.
$$

$\gamma$、$\beta$ 是可学的缩放与平移，本讲取 $1$ 与 $0$。$\varepsilon$ 是防止除以零的小数，手算取 $0$。

**逐位置的前馈。** 每个位置各自过一个两层的网（第74讲），外面同样套残差与按行。跨位置的只有自注意力。本讲不算这一块。

**推导一：打分只看差。** 一行打分都加同一个数 $c$，$a_{ij}$ 的分子分母同乘 $e^{c}$，约掉，权重不变。所以一行打分全相等时，不论等于 $1$、$0$ 还是 $5$，每枚权重都是 $\dfrac{1}{n}$，汇合就是值的平均：$\dfrac{4+2}{2}=3$。

**推导二：为什么除以 $\sqrt{d_k}$。** 设查询与键的各分量独立，均值 $0$、方差 $1$。在各分量彼此独立、均值 $0$、方差 $1$ 的假设下，点积 $\sum_{j=1}^{d_k}q_jk_j$ 每一项的方差是 $E[q_j^2]E[k_j^2]=1$，$d_k$ 项相加，方差是 $d_k$。除以 $\sqrt{d_k}$，方差回到 $1$，软最大不至于过早挤成一枚独大。这是尺度上的假设，不是定理。本讲 $d_k=1$，除数是 $1$。本讲 $d_k=1$，除数是 $1$。

**推导三：不加位置，换序只让输出换序。** 换序矩阵记作 $\Pi$，每行每列只有一个 $1$，$\Pi^{\mathsf T}\Pi=I$。输入换成 $\Pi X$，打分表变成 $\Pi S\Pi^{\mathsf T}$，按行软最大后权重表是 $\Pi A\Pi^{\mathsf T}$，汇合是

$$
\Pi A\Pi^{\mathsf T}\,\Pi V=\Pi AV.
$$

输出只是原输出换了次序。自注意力本身分不出谁在前，第几位要另外加。

## 92.7　小算例：投回原宽，再加回去

92.4 节停在拼接 $(3,1)$，残差只做在单头那本账上。一般式里，残差加的是乘过 $W^{O}$ 的结果。本讲的值是一维，模型宽度当成 $1$，$W^{O}$ 是两行一列。试三张：

| $W^{O}$ | 投回 | 残差 | 两处之差 |
|---|---|---|---|
| $(1,0)^{\mathsf T}$ | $3\times 1+1\times 0=3$ | $7$ 与 $5$ | $2$ |
| $\left(\dfrac{1}{2},\dfrac{1}{2}\right)^{\mathsf T}$ | $\dfrac{3}{2}+\dfrac{1}{2}=2$ | $6$ 与 $4$ | $2$ |
| $(0,1)^{\mathsf T}$ | $3\times 0+1\times 1=1$ | $5$ 与 $3$ | $2$ |

第一行的数和单头账相同。要两个条件一起成立：子层输入就是值 $4$ 与 $2$（这一面的 $W^{V}$ 取恒等），并且 $W^{O}$ 取 $(1,0)^{\mathsf T}$，把第二面乘成 $0$。第二面的值 $0$ 与 $2$ 是直接写下的，不是 $(4,2)$ 乘一个数。真模型的 $W^{O}$ 是学出来的。第一行投回 $3$，残差 $4+3=7$、$2+3=5$，差 $2$。第二行投回 $2$，残差 $4+2=6$、$2+2=4$，差 $2$。第三行投回 $1$，残差 $4+1=5$、$2+1=3$，差 $2$。三行加上的数是 $3$、$2$、$1$，残差的两处都跟着少 $1$，差不变。对调值的次序以后，汇合仍是 $3$，残差变成 $2+3=5$ 与 $4+3=7$，只是 $7$ 与 $5$ 换了位置。$7-5=2$ 仍在。位置 $0$ 的向量是 $(0,1)$。词 $(1,0)$ 加上去是 $(1,1)$；对调后词 $(2,0)$ 加上去是 $(2,1)$。$(2,1)-(1,1)=(1,0)$，多出来的是内容从 $1$ 换成 $2$，位置那一维没有变。

三行的差都是 $2$，等于原值之差 $4-2$。投回的数是 $3$、$2$、$1$，相邻都少 $1$。残差的大的那一处是 $7$、$6$、$5$，也是相邻少 $1$；小的那一处是 $5$、$4$、$3$，同样相邻少 $1$。加上的数变了，两处之差不变。三张投影投回 $3$、$2$、$1$，三数之和是 $3+2+1=6$，再除以 $3$ 得 $2$。头尾两张是 $3$ 与 $1$，平均 $\dfrac{3+1}{2}=2$，和三张一起的平均相同，因为中间那张自己就是 $2$。残差对的均值是 $6$、$5$、$4$，三数之和 $6+5+4=15$，再除以 $3$ 得 $5$。原值的平均是 $\dfrac{4+2}{2}=3$，加上投影的平均 $2$，得到 $3+2=5$。残差是原值加投影，平均也按这个加。脚本印出汇合 $3$ 与 $3$，两处之和是 $3+3=6$。残差 $7$ 与 $5$ 之和是 $7+5=12$。$12-6=6$，少掉的 $6$ 正是原值 $4+2$。因为每一处残差都是原值加汇合，两处相加就是原值之和再加汇合之和。$4+2+3+3=12$。归一化印成 $1$ 与 $-1$，两数之和是 $0$，均值是 $0$。送进去之前的均值是 $2$，按行先减去这个 $2$，所以 $3-2=1$、$1-2=-1$。若把残差 $7$ 与 $5$ 送进去，减去的是 $6$ 不是 $2$，得到的仍是 $1$ 与 $-1$，可减去的数不同。本讲按行减的是 $2$。位置那一节印出底数幂 $1$，因为 $10000^{0}=1$。偶数正弦是 $0$，奇数余弦是 $1$。位置是 $0$ 与 $1$，词是 $1$ 与 $0$，相加是 $1$ 与 $1$。$1+0=1$，$0+1=1$。两处汇合都印成 $3$，位置向量还没有把两处拉开，因为这一节的打分全写成 $1$，位置没有进入打分。第二面汇合印成 $1$，拼接印成 $3$ 与 $1$。$3-1=2$，和原值之差 $4-2$ 同数。$3+3=6$，又和原值 $4+2$ 相同：一个是两处汇合相加，一个是两处原值相加。位置那一维仍是 $1$，没有进入打分，所以两处汇合仍相等。若把 $3$ 与 $1$ 的平方和 $2$ 除以 $2-1$，方差是 $2$，标准差是 $\sqrt{2}$，结果约是 $0.7071$ 与 $-0.7071$。$1-0.7071=0.2929$，比按个数除得到的 $\pm 1$ 更靠近 $0$。按行除以个数，不除以个数减一。$3$ 与 $3$ 的方差是 $0$，除以 $0$ 没有定义。加上 $\varepsilon$ 后两处都是 $0$。所以本讲只把拼接的 $3$ 与 $1$ 送进按行。

**对调。** 把值的次序换成 $2$ 与 $4$。打分仍全是 $1$，汇合仍是 $3$ 与 $3$，残差 $2+3=5$、$4+3=7$，只是 $7$ 与 $5$ 换了位置，正合推导三。先加位置就不同了：两个词取 $(1,0)$ 与 $(2,0)$，位置 $1$ 的向量记作 $\boldsymbol{r}$，不算它。原序第 $0$ 位是 $(1,0)+(0,1)=(1,1)$；对调后第 $0$ 位是 $(2,0)+(0,1)=(2,1)$。当且仅当 $\boldsymbol{r}\neq(0,1)$，对调后的输入才不再是原输入换个次序；$\boldsymbol{r}=(0,1)$ 时，对调后仍是原输入换序。第八十九讲「狗咬人」与「人咬狗」的难处，由这一笔补上。

## 92.8　常见误区与反例

**误区一：打分是 $1$，权重就是 $1$。** 两枚打分都是 $1$，差是 $1-1=0$。权重只看这个差，所以各是 $\dfrac{e}{2e}=\dfrac{1}{2}$。$\dfrac{1}{2}+\dfrac{1}{2}=1$，总和是 $1$，不是 $1+1=2$。汇合因此是值的平均 $3$，不是 $4+2=6$。

**误区二：$7$ 与 $5$ 按行也得 $1$ 与 $-1$，所以 $1$ 与 $-1$ 来自残差。** 任取 $a>b$：均值 $\dfrac{a+b}{2}$，离均差 $\pm\dfrac{a-b}{2}$，方差 $\left(\dfrac{a-b}{2}\right)^{2}$，标准差 $\dfrac{a-b}{2}$，结果总是 $1$ 与 $-1$。$7-5=2$，$3-1=2$，两对的间距都是 $2$，一半都是 $1$，标准差都是 $1$。$3$ 与 $1$、$7$ 与 $5$ 都一样。两个特征按行只留下谁大，结果相同不说明来历相同。

**误区三：$3$ 与 $3$ 也能按行。** 若把单头整行的 $3$ 与 $3$ 当两个特征，均值 $3$，离差都是 $0$，平方和是 $0$，方差 $0$，除以 $0$ 没有定义。加上 $\varepsilon$ 后是 $\dfrac{0}{\sqrt{\varepsilon}}=0$，两处都压成 $0$。和 $3$ 与 $1$ 得到的 $1$ 与 $-1$ 差了整整 $1$。

**误区四：除以个数减一也行。** $3$ 与 $1$ 的平方和 $2$ 除以 $2-1$，方差是 $2$，标准差 $\sqrt{2}$，结果是 $\dfrac{1}{\sqrt{2}}\approx 0.7071$ 与 $-0.7071$。$1-0.7071=0.2929$。按行除以个数 $2$，方差是 $1$，结果才是 $\pm 1$。$\dfrac{2}{1}=2$，两种方差差一倍，标准差差 $\sqrt{2}$ 倍。

## 本讲小结

1. **位置 $0$、维度 $2$：偶数正弦 $0$，奇数余弦 $1$，向量 $(0,1)$。** 词 $(1,0)$ 相加得 $(1,1)$。加之前点积 $1\times 0+0\times 1=0$。
2. **自注意力：值 $4$ 与 $2$，权重各 $\dfrac{e}{2e}=\dfrac{1}{2}$，汇合 $2+1=3$。** 第九十一讲值 $4$ 与 $0$ 时是 $2$，$3-2=1$。
3. **第二面值 $0$ 与 $2$，汇合 $1$。拼接是 $(3,1)$。** $3+1=4$，$3-1=2$。
4. **单头残差是 $7$ 与 $5$。** $4+3=7$，$2+3=5$，$7-5=2$。原值没有扔掉。三张投影投回 $3$、$2$、$1$，残差大的一处是 $7$、$6$、$5$，差仍是 $2$。
5. **$3$ 与 $1$ 按行：均值 $2$，方差 $1$，得到 $1$ 与 $-1$。** 加 $10^{-5}$ 后约是 $0.999995$，比 $1$ 小 $0.000005$。若除以 $2-1$，约是 $\pm 0.7071$。若把 $7$ 与 $5$ 送进同一套按行，数字也是 $1$ 与 $-1$。要靠来历分开。
6. **一般式是 $\mathrm{softmax}\!\left(\dfrac{QK^{\mathsf T}}{\sqrt{d_k}}\right)V$，多面拼接再乘 $W^{O}$。** 单头账是子层输入等于这些值、并且 $W^{O}$ 取 $(1,0)^{\mathsf T}$ 的特例。打分只看差；不加位置，换序只让输出换序。
7. **库和实现会换，自注意力、位置与残差不换。** 种子 $92$，不下载。屏风不是铜镜。
