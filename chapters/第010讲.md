# 第10讲　有方向的数：向量与点积

> 一个数只说"有多少"，一个向量还要说"往哪儿"。

---

## 导语

《韩非子·有度》里有一句话："故先王立司南以端朝夕。"今天博物馆里常见的那把司南，是一只磁石琢成的勺子，放在一块光滑的铜盘上，轻轻一拨，勺子转几圈，停下来时勺柄指向南方。需要说明的是，这个"勺子加铜盘"的样子是二十世纪学者根据古籍所作的复原，古时的司南究竟什么样，学界至今仍有讨论。不过它讲的道理很清楚：**光知道"多远"还不够，还得知道"朝哪儿"。**

上一讲，我们走完了第一篇：有了数据、有了工具，也从头到尾跑通了一个项目。可一路上留下了好几个"说不清"：K 近邻说两瓶酒"离得近"，这个"近"到底怎么量？逻辑回归把权重和 13 个化学指标相乘再相加，这个"加权求和"在几何上是什么意思？标准化之后 K 近邻为什么突然变准了？

这些问题的答案，都藏在一个最基本的数学对象里：**向量**。从这一讲开始，我们进入第二篇"数学之基"。第一站，就是这支"有方向的箭"。

这一讲回答五个问题：

1. 向量是什么？为什么说一瓶酒就是一个 13 维的向量？
2. 向量相加、乘一个数，在几何上分别是什么动作？
3. 怎样给向量量"长度"？为什么会有好几把不同的尺子？
4. 点积是什么？它和夹角、投影有什么关系？
5. 余弦相似度和欧氏距离有什么区别？它们和机器学习模型的"打分"有什么关系？

## 10.1　向量：有方向的数，也是一行数据

### 标量与向量

只有大小、没有方向的量，叫**标量**（scalar）：气温 25 度、体重 66 公斤、一瓶酒的酒精度 14.23。

既有大小、又有方向的量，叫**向量**（vector）：风从西北吹来，每秒 5 米；纤夫往岸上拉，用了 300 牛的力。光说"5 米每秒"，你不知道该把风帆朝哪边转。

在平面上，向量画成一支**箭头**：箭尾在原点，箭尖落在某个点上。箭头 $\boldsymbol{a}$ 从原点 $(0, 0)$ 指向 $(3, 4)$，我们就写

$$
\boldsymbol{a} = (3, 4)
$$

粗体的 $\boldsymbol{a}$ 表示"这是一个向量"，括号里的 3 和 4 叫它的**分量**（component）：向右走 3，向上走 4。第 $i$ 个分量记作 $a_i$，读作"a 下标 i"，于是 $a_1 = 3$，$a_2 = 4$。

### 两种看法，同一个东西

向量有两种看法，这一讲会反复在它们之间切换：

| 看法 | 向量是什么 | 适合想什么问题 |
|---|---|---|
| 几何的看法 | 一支有长度、有方向的箭头 | 多长？朝哪儿？两支箭夹多大的角？ |
| 数据的看法 | 一行排好顺序的数 | 每一项是多少？怎样逐项计算？ |

二维、三维的向量，画得出箭头；四维以上画不出来，但"一行数"的看法照样成立。$n$ 个分量的向量写成

$$
\boldsymbol{x} = (x_1, x_2, \ldots, x_n) \in \mathbb{R}^n
$$

$\mathbb{R}$ 是全体实数，$\mathbb{R}^n$ 读作"R n"，表示由 $n$ 个实数组成的所有向量，也就是"$n$ 维空间"。符号 $\in$ 读作"属于"。

### 一瓶酒，就是 13 维空间里的一支箭

第2讲说过，特征矩阵 $\boldsymbol{X} \in \mathbb{R}^{n \times m}$ 的每一行是一个样本。现在可以换个说法：**每一行，就是 $m$ 维空间里的一个向量。** 葡萄酒数据集里第 0 瓶酒（代码见 `code/l010_basics.py`）：

```text
第0瓶酒： [  14.23    1.71    2.43   15.6   127.      2.8     3.06    0.28    2.29
    5.64    1.04    3.92 1065.  ]
```

13 个化学指标，就是 13 个分量。这瓶酒是 $\mathbb{R}^{13}$ 里的一个点，也是从原点射向这个点的一支箭。178 瓶酒，就是 178 支箭。K 近邻找"最近的邻居"、逻辑回归给每瓶酒"打分"，说到底都是在比较、组合这些箭。

本讲有时也会写 $\boldsymbol{x}^{\top}$（读作"x 转置"），这是第6讲见过的写法：把一列数横过来写成一行。眼下你只要知道 $\boldsymbol{x}^{\top}\boldsymbol{y}$ 和本讲的 $\boldsymbol{x} \cdot \boldsymbol{y}$ 是同一个运算即可，第11讲讲矩阵时再细说行与列。

## 10.2　加法与数乘：走两段路，把箭拉长

### 加法：首尾相接

两个向量相加，就是**对应分量相加**：

$$
\boldsymbol{a} + \boldsymbol{b} = (a_1 + b_1,\ a_2 + b_2,\ \ldots,\ a_n + b_n)
$$

例如 $\boldsymbol{a} = (3, 1)$，$\boldsymbol{b} = (1, 2)$，则 $\boldsymbol{a} + \boldsymbol{b} = (4, 3)$。

几何上，这是"走两段路"：先沿 $\boldsymbol{a}$ 走到 $(3, 1)$，再从那里沿 $\boldsymbol{b}$ 走，向右 1、向上 2，到达 $(4, 3)$。从起点直接指向终点的那支箭，就是 $\boldsymbol{a} + \boldsymbol{b}$。先走 $\boldsymbol{b}$ 再走 $\boldsymbol{a}$，终点一样，两条路线围成一个平行四边形。

### 数乘：拉长、缩短、调头

一个数 $c$ 乘以向量，叫**数乘**（scalar multiplication），就是每个分量都乘 $c$：

$$
c\,\boldsymbol{a} = (c\,a_1,\ c\,a_2,\ \ldots,\ c\,a_n)
$$

$2\boldsymbol{a} = (6, 2)$，方向不变，长度变成两倍；$0.5\boldsymbol{a} = (1.5, 0.5)$，长度减半；$-\boldsymbol{a} = (-3, -1)$，长度不变，方向调头。不论乘什么数，箭头都还躺在同一条直线上。

![向量加法与数乘](figs/l010_add_scale.png)

上图左边：黑色的 $\boldsymbol{a}$ 和青色的 $\boldsymbol{b}$ 首尾相接，两条虚线是"另一种走法"，两条路殊途同归，金色的对角线就是 $\boldsymbol{a} + \boldsymbol{b} = (4, 3)$。右边：四支箭都在同一条直线上，金色的 $2\boldsymbol{a}$ 最长，青色的 $0.5\boldsymbol{a}$ 只有一半，红色的 $-\boldsymbol{a}$ 掉头指向左下。

### 减法：从一个箭尖指向另一个箭尖

$\boldsymbol{b} - \boldsymbol{a}$ 就是 $\boldsymbol{b} + (-1)\boldsymbol{a}$。几何上，它是**从 $\boldsymbol{a}$ 的箭尖指向 $\boldsymbol{b}$ 的箭尖**的那支箭：因为 $\boldsymbol{a} + (\boldsymbol{b} - \boldsymbol{a}) = \boldsymbol{b}$，先走到 $\boldsymbol{a}$，再走 $\boldsymbol{b} - \boldsymbol{a}$，就到了 $\boldsymbol{b}$。

减法在机器学习里到处都是。第6讲标准化时写的 $\boldsymbol{x} - \boldsymbol{\mu}$，就是把每瓶酒的箭，改成"从平均酒出发"的箭；下一节的距离，则是两瓶酒之差的长度。

纸笔例题会用到的两个向量 $\boldsymbol{a} = (3, 4)$、$\boldsymbol{b} = (4, 3)$，程序核对的结果是：

```text
a+b = [7. 7.]  2a = [6. 8.]  -a = [-3. -4.]  b-a = [ 1. -1.]
```

## 10.3　范数：给箭量长度

### L2 范数：拉一根直线

箭头 $\boldsymbol{a} = (3, 4)$ 有多长？向右 3、向上 4，斜边按勾股定理是 $\sqrt{3^2 + 4^2} = 5$。推广到 $n$ 维：

$$
\|\boldsymbol{x}\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2} = \sqrt{\sum_{i=1}^{n} x_i^2}
$$

$\|\boldsymbol{x}\|_2$ 读作"x 的二范数"或"L2 范数"（L2 norm），两道竖线表示"长度"，下标 2 指的是"平方再开方"。$\sum_{i=1}^{n}$ 读作"对 i 从 1 到 n 求和"。不写下标的 $\|\boldsymbol{x}\|$，默认就是 L2 范数。

**范数**（norm），就是一把给向量量长度的尺子。L2 是最常用的一把，量的是"拉一根直线"的长度。

### L1 范数：沿着街巷走

唐长安城的街道横平竖直，把城切成一个个方方正正的里坊。从城里一个路口走到另一个路口，没法斜穿坊墙，只能先东西走、再南北走。这时"有多远"应该按街巷算：

$$
\|\boldsymbol{x}\|_1 = |x_1| + |x_2| + \cdots + |x_n| = \sum_{i=1}^{n} |x_i|
$$

这是 **L1 范数**，$|x_i|$ 是绝对值。$\boldsymbol{a} = (3, 4)$ 的 L1 范数是 $3 + 4 = 7$。用它量出来的距离叫**曼哈顿距离**（Manhattan distance），因为纽约曼哈顿的街道也是棋盘格。

### L∞ 范数：只看最长的那一项

$$
\|\boldsymbol{x}\|_\infty = \max_i |x_i|
$$

读作"x 的无穷范数"，$\max_i$ 表示"在所有 $i$ 里取最大的"。$\boldsymbol{a} = (3, 4)$ 的 L∞ 范数是 $\max(3, 4) = 4$。它只关心"最远的那一个方向走了多远"。国际象棋里的王，横、竖、斜一步都只算一步，从一格走到另一格最少要走的步数，正是这种算法。

三把尺子其实是一家人。对任意 $p \geq 1$，定义

$$
\|\boldsymbol{x}\|_p = \left( \sum_{i=1}^{n} |x_i|^p \right)^{1/p}
$$

$p = 1$ 是 L1，$p = 2$ 是 L2，$p$ 越来越大时，最大的那一项压倒其余各项，极限就是 L∞。由 $\|\boldsymbol{x} - \boldsymbol{y}\|_p$ 定义的距离叫**闵可夫斯基距离**（Minkowski distance）。scikit-learn 里 K 近邻的默认度量 `metric="minkowski"` 配上默认的 `p=2`，就是欧氏距离。

不论哪把尺子，都满足三条"像长度"的性质：长度不为负，只有零向量长度为 0；向量放大 $c$ 倍，长度放大 $|c|$ 倍；两边之和不小于第三边，即 $\|\boldsymbol{x} + \boldsymbol{y}\| \leq \|\boldsymbol{x}\| + \|\boldsymbol{y}\|$，这叫**三角不等式**。

### 三种"单位圆"

所有"长度等于 1"的点连起来，叫这把尺子下的**单位圆**。用不同的尺子，"圆"长得完全不一样：

![三种范数下的单位圆](figs/l010_unit_balls.png)

左图三条曲线：

- L2 下，$x^2 + y^2 = 1$，是我们熟悉的圆；
- L1 下，$|x| + |y| = 1$，是一个立在尖上的**菱形**，四个尖角正好落在坐标轴上；
- L∞ 下，$\max(|x|, |y|) = 1$，是一个**正方形**。

三个形状一层套一层：菱形在最里面，方形在最外面。这说明同一个点，L1 量出来最长，L∞ 最短，L2 居中。右图就是一个例子：从原点到 $(3, 4)$，沿街巷走是 7（青色折线），拉直线是 5（金色斜线），只看最长的一项是 4（黑色虚线）。

菱形的尖角落在坐标轴上，这个细节以后很重要：第26讲的 Lasso 用 L1 范数约束权重，结果常常把一些权重压成恰好为 0，原因就藏在这些尖角里。

### 一瓶酒有多"长"

第 0 瓶酒的 L2 范数是多少？程序输出：

```text
L2 范数 = 1072.79  np.linalg.norm = 1072.79
脯氨酸 = 1065.0  脯氨酸平方占平方和比例 = 0.9855
```

整支箭长 1072.79，其中脯氨酸一项是 1065。在平方和里，脯氨酸一项就占了 98.55%。**这支 13 维的箭，几乎完全朝着"脯氨酸"那个方向。** 其余 12 个指标在长度里几乎没有存在感。记住这个数字，下一节它会解释一个老问题。

## 10.4　距离：差向量的长度

两个点之间的距离，就是它们**差向量的长度**：

$$
d(\boldsymbol{x}, \boldsymbol{y}) = \|\boldsymbol{x} - \boldsymbol{y}\|
$$

用不同的范数，得到不同的距离：

| 范数 | 距离名称 | 公式 | $\boldsymbol{a} = (3,4)$ 与 $\boldsymbol{b} = (4,3)$ |
|---|---|---|---|
| L2 | 欧氏距离（Euclidean distance） | $\sqrt{\sum (x_i - y_i)^2}$ | $\sqrt{1^2 + 1^2} = \sqrt{2} \approx 1.4142$ |
| L1 | 曼哈顿距离 | $\sum \|x_i - y_i\|$ | $1 + 1 = 2$ |
| L∞ | 切比雪夫距离（Chebyshev distance） | $\max_i \|x_i - y_i\|$ | $\max(1, 1) = 1$ |

第1讲给 K 近邻算距离时用的，就是第一行；第5讲、第6讲写的 `np.sqrt(((a - b) ** 2).sum())`，就是"先相减、再求 L2 范数"。

现在回答第2讲留下的老问题：为什么不标准化的 K 近邻很差？看第 0 瓶和第 1 瓶酒：

```text
第1瓶酒： [  13.2     1.78    2.14   11.2   100.      2.65    2.76    0.26    1.28
    4.38    1.05    3.4  1050.  ]
第0瓶与第1瓶：欧氏距离 = 31.27  只看脯氨酸之差 = 15.0
```

两瓶酒的距离是 31.27。差向量里，镁差了 $127 - 100 = 27$，脯氨酸差了 15，这两项的平方 $729 + 225 = 954$，已经占了距离平方（约 978）的绝大部分。而第7讲用"极差÷标准差"排出来、最能拉开品种差距的类黄酮，在这两瓶之间只差 0.3（3.06 对 2.76），平方后不到 0.1，几乎被淹没。**欧氏距离对每个分量一视同仁，于是数值大的特征说了算。** 标准化把每个特征拉到同一个尺度，就是为了让每一项都有发言权。第23讲还会系统讨论特征缩放。

## 10.5　点积：两种看法，一个数

### 看法一：对应相乘，再相加

第6讲已经见过点积：

$$
\boldsymbol{x} \cdot \boldsymbol{y} = x_1 y_1 + x_2 y_2 + \cdots + x_n y_n = \sum_{i=1}^{n} x_i y_i
$$

读作"x 点乘 y"。它把两个向量变成**一个数**。对 $\boldsymbol{a} = (3, 4)$、$\boldsymbol{b} = (4, 3)$：

$$
\boldsymbol{a} \cdot \boldsymbol{b} = 3 \times 4 + 4 \times 3 = 24
$$

注意：$\boldsymbol{x} \cdot \boldsymbol{x} = \sum x_i^2 = \|\boldsymbol{x}\|^2$，一个向量和自己的点积，就是长度的平方。

### 看法二：长度、长度、夹角

同一个数，还有一个几何的写法：

$$
\boldsymbol{x} \cdot \boldsymbol{y} = \|\boldsymbol{x}\|\, \|\boldsymbol{y}\| \cos\theta
$$

$\theta$ 读作"西塔"，是两支箭之间的夹角；$\cos\theta$ 是它的余弦。反过来，夹角可以由点积求出：

$$
\cos\theta = \frac{\boldsymbol{x} \cdot \boldsymbol{y}}{\|\boldsymbol{x}\|\, \|\boldsymbol{y}\|}
$$

对 $\boldsymbol{a}$、$\boldsymbol{b}$：$\cos\theta = 24 / (5 \times 5) = 0.96$，$\theta \approx 16.26°$。两支箭靠得很近。

两种看法为什么相等？用第6讲的展开式：

$$
\|\boldsymbol{x} - \boldsymbol{y}\|^2 = \|\boldsymbol{x}\|^2 + \|\boldsymbol{y}\|^2 - 2\,\boldsymbol{x} \cdot \boldsymbol{y}
$$

再看三角形的**余弦定理**：以 $\boldsymbol{x}$、$\boldsymbol{y}$ 为两边、夹角为 $\theta$，第三边就是 $\boldsymbol{x} - \boldsymbol{y}$，于是

$$
\|\boldsymbol{x} - \boldsymbol{y}\|^2 = \|\boldsymbol{x}\|^2 + \|\boldsymbol{y}\|^2 - 2\|\boldsymbol{x}\|\, \|\boldsymbol{y}\| \cos\theta
$$

两式一比，$\boldsymbol{x} \cdot \boldsymbol{y} = \|\boldsymbol{x}\|\, \|\boldsymbol{y}\| \cos\theta$。用 $\boldsymbol{a}$、$\boldsymbol{b}$ 核对：左边 $\|\boldsymbol{a} - \boldsymbol{b}\|^2 = 2$，右边 $25 + 25 - 2 \times 24 = 2$。

### 投影：日晷上的影子

日晷的晷针被太阳一照，在盘面上投下一道影子。影子有多长，取决于针有多长、阳光斜到什么程度。点积的第二种看法，正是一个"影子"：

$$
\text{$\boldsymbol{b}$ 在 $\boldsymbol{a}$ 方向上的投影长度} = \|\boldsymbol{b}\| \cos\theta = \frac{\boldsymbol{a} \cdot \boldsymbol{b}}{\|\boldsymbol{a}\|}
$$

从 $\boldsymbol{b}$ 的箭尖向 $\boldsymbol{a}$ 所在的直线作垂线，垂足到原点的长度就是投影长度。所以

$$
\boldsymbol{a} \cdot \boldsymbol{b} = \|\boldsymbol{a}\| \times (\text{$\boldsymbol{b}$ 在 $\boldsymbol{a}$ 上的影子长})
$$

对 $\boldsymbol{a}$、$\boldsymbol{b}$：影子长 $24 / 5 = 4.8$，影子的终点是 $4.8 \times (0.6, 0.8) = (2.88, 3.84)$。

![点积的投影与夹角](figs/l010_projection.png)

左图：灰色虚线是从 $\boldsymbol{b}$ 的箭尖落到 $\boldsymbol{a}$ 上的垂线，金色粗线（为了看清，画在 $\boldsymbol{a}$ 旁边平行的位置）就是长 4.8 的影子，比 $\boldsymbol{a}$ 本身的 5 略短。点积 $24 = 5 \times 4.8$。

物理里也有现成的例子。纤夫在岸上拉船，绳子斜着，船沿河道走。真正推船前进的，只有拉力在河道方向上的那一份。拉力 $\boldsymbol{F}$ 沿位移 $\boldsymbol{s}$ 做的**功**，正是 $\boldsymbol{F} \cdot \boldsymbol{s} = \|\boldsymbol{F}\|\, \|\boldsymbol{s}\| \cos\theta$：绳子越贴近河道，$\theta$ 越小，力气越不白费。

### 夹角决定正负；正交

$\cos\theta$ 的正负，决定了点积的正负（长度永远不为负）。右图三支箭：

- **锐角**（$\theta < 90°$）：$\cos\theta > 0$，点积为正，两支箭"大致同向"；
- **直角**（$\theta = 90°$）：$\cos\theta = 0$，点积为 0，影子缩成一个点；
- **钝角**（$\theta > 90°$）：$\cos\theta < 0$，点积为负，影子落到了反方向。

点积为 0 的两个向量叫**正交**（orthogonal），就是"互相垂直"。例如 $(3, 4) \cdot (-4, 3) = -12 + 12 = 0$；$(3, 4) \cdot (-3, -4) = -25$，余弦为 $-1$，两支箭正好反向。

正交时，勾股定理在任意维都成立：$\|\boldsymbol{x} + \boldsymbol{y}\|^2 = \|\boldsymbol{x}\|^2 + \|\boldsymbol{y}\|^2 + 2\,\boldsymbol{x} \cdot \boldsymbol{y}$，中间一项为 0。

### 影子不会比针长：柯西—施瓦茨不等式

因为 $-1 \leq \cos\theta \leq 1$，立刻得到

$$
|\boldsymbol{x} \cdot \boldsymbol{y}| \leq \|\boldsymbol{x}\|\, \|\boldsymbol{y}\|
$$

这就是**柯西—施瓦茨不等式**（Cauchy–Schwarz inequality）。直觉是：**影子再长，也长不过晷针本身。** 只有当两支箭在同一条直线上（同向或反向）时，等号才成立。在高维空间里我们画不出"夹角"，恰恰是这条不等式保证了 $\frac{\boldsymbol{x} \cdot \boldsymbol{y}}{\|\boldsymbol{x}\|\|\boldsymbol{y}\|}$ 一定落在 $[-1, 1]$ 之间，于是可以放心地把它定义成"夹角的余弦"。

程序里随机生成了 10 万对 5 维向量，这个比值的绝对值最大是：

```text
10万对随机5维向量，|x·y|/(||x||·||y||) 最大值 = 0.9952
```

很接近 1，但没有一对越过 1。

## 10.6　余弦相似度：只看方向，不看长度

### 定义

把上面的 $\cos\theta$ 单独拿出来，就是**余弦相似度**（cosine similarity）：

$$
\operatorname{cos\_sim}(\boldsymbol{x}, \boldsymbol{y}) = \frac{\boldsymbol{x} \cdot \boldsymbol{y}}{\|\boldsymbol{x}\|\, \|\boldsymbol{y}\|}
$$

它的取值在 $-1$ 到 $1$ 之间：1 表示方向完全相同，0 表示正交，$-1$ 表示完全相反。如果各分量都不为负（比如词频、购买次数），它就落在 0 到 1 之间。$\boldsymbol{a}$、$\boldsymbol{b}$ 的余弦相似度是 0.96。

### 一篇文章复制两遍

把一篇文章看成一个**词频向量**：每个分量是某个词出现的次数（第2讲的"词袋"）。假设一篇短文的词频是 $(2, 1, 0, 3)$，把全文复制一遍贴在后面，词频变成 $(4, 2, 0, 6)$。内容一字未变，只是变长了。

```text
doc = [2. 1. 0. 3.]  doc复制两遍 = [4. 2. 0. 6.]
余弦相似度 = 1.0  欧氏距离 = 3.7417
```

欧氏距离说它们相距 3.74，好像是两篇不同的文章；余弦相似度说它们完全一样。**数乘只改变长度、不改变方向，而余弦相似度只看方向。** 判断"两篇文章是不是在说同一件事"，我们关心的是用词的比例，而不是篇幅长短，这时余弦更合适。信息检索里把文档表示成向量、用余弦给它们排序，是一种由来已久的经典做法。

### 单位化：先把箭都裁成一样长

把向量除以自己的长度，得到长度为 1 的**单位向量**（unit vector），这一步叫**单位化**（normalization）：

$$
\hat{\boldsymbol{x}} = \frac{\boldsymbol{x}}{\|\boldsymbol{x}\|}
$$

$\hat{\boldsymbol{x}}$ 读作"x 帽"。$\boldsymbol{a} = (3, 4)$ 单位化后是 $(0.6, 0.8)$。单位化之后，余弦相似度就是普通的点积：$\hat{\boldsymbol{u}} \cdot \hat{\boldsymbol{v}} = \cos\theta$。

单位向量之间的欧氏距离和余弦之间，有一个干净的关系。把展开式里的两个长度都换成 1：

$$
\|\boldsymbol{u} - \boldsymbol{v}\|^2 = 1 + 1 - 2\,\boldsymbol{u} \cdot \boldsymbol{v} = 2 - 2\cos\theta
$$

对 $\boldsymbol{a}$、$\boldsymbol{b}$：$\boldsymbol{u} = (0.6, 0.8)$，$\boldsymbol{v} = (0.8, 0.6)$，$\|\boldsymbol{u} - \boldsymbol{v}\|^2 = 0.2^2 + 0.2^2 = 0.08$，而 $2 - 2 \times 0.96 = 0.08$。

```text
||u-v||^2 = 0.08  2-2cos = 0.08
```

这条式子说明：**先单位化，再用欧氏距离找最近邻，排序和直接用余弦相似度完全一样。** 余弦越大，距离越小，一一对应。很多检索系统正是这样做的：先把所有向量单位化，再交给擅长欧氏距离的工具去找最近邻。scikit-learn 里还有一个"余弦距离" $1 - \cos\theta$，也是同一个意思的另一种写法。

### 该用哪一个

| | 欧氏距离 | 余弦相似度 |
|---|---|---|
| 看什么 | 位置：方向和长度都算 | 只看方向 |
| 把一个向量放大 3 倍 | 距离变了 | 不变 |
| 适合 | 长度本身有意义：身高体重、化学浓度、坐标 | 长度是"噪声"：文章篇幅、用户活跃程度 |
| 典型场景 | K 近邻（标准化后）、聚类 | 文本相似度、推荐、词向量（第90讲） |

一句话：**长度有含义，用距离；长度是干扰，用余弦。** 拿不准时，就两种都试，用验证集说话。

## 10.7　点积就是打分：$\boldsymbol{w} \cdot \boldsymbol{x} + b$

第3讲的感知机，对一个输入 $\boldsymbol{x}$ 先算

$$
z = \boldsymbol{w} \cdot \boldsymbol{x} + b = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b
$$

$\boldsymbol{w}$ 是**权重向量**（weight），$b$ 是**偏置**（bias），$z$ 是一个分数，再看分数是正是负来分类。第19讲的线性回归、第28讲的逻辑回归、第73讲的神经元，核心都是这一行。

现在可以用几何的眼光看它了：

1. **点积是"在 $\boldsymbol{w}$ 方向上走了多远"。** 由投影公式，$\boldsymbol{w} \cdot \boldsymbol{x} = \|\boldsymbol{w}\| \times (\boldsymbol{x}\ \text{在}\ \boldsymbol{w}\ \text{上的影子长})$。权重向量 $\boldsymbol{w}$ 指出了"哪个方向是好的"，打分就是看样本朝这个方向走得有多远。
2. **$z = 0$ 是一条分界线。** 所有满足 $\boldsymbol{w} \cdot \boldsymbol{x} + b = 0$ 的点，在 $\boldsymbol{w}$ 上的影子一样长，它们排成一条与 $\boldsymbol{w}$ **垂直**的直线（高维时是一个平面）。分界线一侧打正分，另一侧打负分。
3. **分数和长度有关。** 和余弦不同，点积会随 $\boldsymbol{x}$ 变长而变大。所以线性模型对特征的尺度很敏感，这又是一个需要标准化的理由。

一个三维的小例子：$\boldsymbol{w} = (0.5, -1, 2)$，$b = -1$。

$$
\boldsymbol{x}_1 = (2, 1, 1):\quad 0.5 \times 2 - 1 \times 1 + 2 \times 1 - 1 = 1.0
$$

$$
\boldsymbol{x}_2 = (1, 3, 0.5):\quad 0.5 \times 1 - 1 \times 3 + 2 \times 0.5 - 1 = -2.5
$$

把两个样本堆成矩阵，`X @ w + b` 一次算完（第6讲）：

```text
w·x1+b = 1.0  w·x2+b = -2.5  X@w+b = [ 1.  -2.5]
```

$\boldsymbol{x}_1$ 落在正的一侧，$\boldsymbol{x}_2$ 落在负的一侧。第一篇里我们看到的"加权求和"，从此有了一幅图：**一支箭（权重）指出方向，每个样本在它上面投下影子，影子的长短就是分数。**

这个"用点积衡量两个东西有多对得上"的想法，会一路走到第91讲的注意力机制：查询和键之间算的，也是点积。

### 第一步：四个函数

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

def l2(x):   return np.sqrt(np.sum(x ** 2))
def l1(x):   return np.sum(np.abs(x))
def linf(x): return np.max(np.abs(x))
def dot(x, y): return np.sum(x * y)
def cos_sim(x, y): return dot(x, y) / (l2(x) * l2(y))

a = np.array([3.0, 4.0]); b = np.array([4.0, 3.0])
print("L2(a) =", l2(a), " L1(a) =", l1(a), " Linf(a) =", linf(a))
print("np.linalg.norm:", np.linalg.norm(a), np.linalg.norm(a, 1), np.linalg.norm(a, np.inf))
print("a·b =", dot(a, b), " a@b =", a @ b)
c = cos_sim(a, b)
print("cos =", round(c, 4), " 夹角(度) =", round(np.degrees(np.arccos(c)), 2))
print("sklearn cosine_similarity:", cosine_similarity([a], [b])[0, 0])
print("欧氏距离 =", round(l2(a - b), 4), " 曼哈顿距离 =", l1(a - b), " 切比雪夫距离 =", linf(a - b))
print("b 在 a 上的投影长度 =", dot(a, b) / l2(a), " 投影向量 =", dot(a, b) / l2(a) ** 2 * a)
```

运行结果：

```text

cos = 0.96  夹角(度) = 16.26
```

几点说明：

- `np.linalg.norm(x)` 默认算 L2；第二个参数写 `1` 是 L1，写 `np.inf` 是 L∞。

## 本讲小结

1. **向量是"有方向的数"，也是"一行数据"。** 一瓶酒是 $\mathbb{R}^{13}$ 里的一支箭，特征矩阵的每一行都是一个向量。
2. 加法是**首尾相接**走两段路；数乘是把箭**拉长、缩短或调头**，方向线不变；$\boldsymbol{b} - \boldsymbol{a}$ 从 $\boldsymbol{a}$ 的箭尖指向 $\boldsymbol{b}$ 的箭尖。
3. **范数是量长度的尺子**：L2 拉直线，L1 走街巷，L∞ 只看最长的一项。它们的单位圆分别是圆、菱形、方形。
4. **距离就是差向量的范数。** 欧氏距离对每个分量一视同仁，所以数值大的特征（如脯氨酸）说了算，这正是要标准化的原因。
5. **点积有两种看法：对应相乘再相加，或者 $\|\boldsymbol{x}\|\|\boldsymbol{y}\|\cos\theta$，即一个的长度乘另一个在它上面的影子。** 点积为正同向、为零正交、为负反向；柯西—施瓦茨不等式说影子长不过针本身。
6. **余弦相似度只看方向不看长度**，一篇文章复制两遍余弦仍是 1。单位化后 $\|\boldsymbol{u} - \boldsymbol{v}\|^2 = 2 - 2\cos\theta$，欧氏距离与余弦给出相同的排序。
7. **线性模型的打分 $\boldsymbol{w} \cdot \boldsymbol{x} + b$ 就是点积**：权重指出方向，样本投下影子，$z = 0$ 是一条与 $\boldsymbol{w}$ 垂直的分界线。

**2. 答案：B。** $(2, -1) \cdot (1, 2) = 2 - 2 = 0$。其余三对的点积分别为 4、−2、3（程序核对一致）。C 的点积为负，两者正好反向，不是垂直。

**3. 答案：C。** 数乘只改长度、不改方向，$\boldsymbol{y}$ 与 $\boldsymbol{x}$ 同向，余弦相似度是 1。A：距离是 $\|\boldsymbol{y} - \boldsymbol{x}\| = \|2\boldsymbol{x}\| = 2\|\boldsymbol{x}\| \neq 0$；B：长度变成 3 倍；D：$\boldsymbol{x} \cdot \boldsymbol{y} = 3\,\boldsymbol{x} \cdot \boldsymbol{x}$。以 $\boldsymbol{x} = (1, 2, 0, 4)$ 为例，实测余弦 1.0，欧氏距离 9.1652，$\boldsymbol{x} \cdot \boldsymbol{y} = 63$（是 $\boldsymbol{x} \cdot \boldsymbol{x} = 21$ 的 3 倍）。

**4. 答案：C。** 这是 L1 范数的单位圆。在第一象限它是 $x + y = 1$，一条连接 $(1, 0)$ 和 $(0, 1)$ 的线段，四个象限拼起来是菱形。B 是 L∞ 的单位圆。

**5. 答案：对。** $\boldsymbol{x} \cdot \boldsymbol{y} = \|\boldsymbol{x}\|\|\boldsymbol{y}\|\cos\theta$，两个长度都为正，点积为负只能是 $\cos\theta < 0$，即 $90° < \theta \leq 180°$。

**6. 答案：错。** 余弦为 1 只说明方向相同，长度可以不同。例如 $(2, 1, 0, 3)$ 与 $(4, 2, 0, 6)$ 余弦为 1，却不相等。

**7. 答案：对。** 单位向量满足 $\|\boldsymbol{u} - \boldsymbol{v}\|^2 = 2 - 2\cos\theta$，距离越小，$\cos\theta$ 越大，两者一一对应。

**8. 解：**

（1）$\|\boldsymbol{a}\|_2 = \sqrt{1 + 4 + 4} = 3$；$\|\boldsymbol{b}\|_2 = \sqrt{4 + 0 + 1} = \sqrt{5} \approx 2.2361$；$\boldsymbol{a} \cdot \boldsymbol{b} = 2 + 0 + 2 = 4$；

$$
\cos\theta = \frac{4}{3\sqrt{5}} \approx 0.5963,\qquad \theta \approx 53.40°
$$

（2）$\boldsymbol{a} - \boldsymbol{b} = (-1, 2, 1)$。欧氏距离 $\sqrt{1 + 4 + 1} = \sqrt{6} \approx 2.4495$；曼哈顿距离 $1 + 2 + 1 = 4$；切比雪夫距离 $\max(1, 2, 1) = 2$。

（3）投影长度 $= \boldsymbol{a} \cdot \boldsymbol{b} / \|\boldsymbol{a}\| = 4/3 \approx 1.3333$。

（4）$\boldsymbol{a} \cdot \boldsymbol{c} = 2 - 4 + 2 = 0$，正交。$\boldsymbol{a} + \boldsymbol{c} = (3, 0, 3)$，$\|\boldsymbol{a} + \boldsymbol{c}\|^2 = 9 + 0 + 9 = 18$；$\|\boldsymbol{a}\|^2 + \|\boldsymbol{c}\|^2 = 9 + 9 = 18$，相等，这是三维空间里的勾股定理。

**9. 解：**

（1）由 $\|\boldsymbol{u} - \boldsymbol{v}\|^2 = 2 - 2\cos\theta$，得 $1 = 2 - 2\cos\theta$，$\cos\theta = 0.5$，$\theta = 60°$。几何上，$\boldsymbol{u}$、$\boldsymbol{v}$ 和 $\boldsymbol{u} - \boldsymbol{v}$ 三边都是 1，构成等边三角形，夹角自然是 60°。程序取 $\boldsymbol{u} = (1, 0)$、$\boldsymbol{v} = (\cos 60°, \sin 60°)$ 核对，$\|\boldsymbol{u} - \boldsymbol{v}\| = 1.0$。

（2）

- $\boldsymbol{x}_1$：$2 \times 1 - 1 \times 3 + 0.5 \times 4 - 1 = 2 - 3 + 2 - 1 = 0$，恰好落在分界线上；
- $\boldsymbol{x}_2$：$6 - 1 - 1 - 1 = 3$；
- $\boldsymbol{x}_3$：$4 - 2 + 1 - 1 = 2$。

$\boldsymbol{x}_1$ 翻倍后，$\boldsymbol{w} \cdot (2\boldsymbol{x}_1) = 2 \times 1 = 2$，再加 $b$，分数为 $1$。点积随样本的长度成比例变化，偏置不变，于是原本在分界线上的点跑到了正的一侧。程序输出 `打分 = [0. 3. 2.]`、`2倍x1 的打分 = 1.0`。

**10. 参考代码**（完整脚本见 `code/l010_exercises.py`）：

```python
from sklearn.datasets import load_wine
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.preprocessing import StandardScaler

X, y = load_wine(return_X_y=True)
q = X[0]; rest = np.arange(1, len(X))
d_raw = norm(X[rest] - q, axis=1)
c_raw = cosine_similarity([q], X[rest])[0]
Z = StandardScaler().fit_transform(X)
d_std = norm(Z[rest] - Z[0], axis=1)
c_std = cosine_similarity([Z[0]], Z[rest])[0]
for name, order in [("原始-欧氏", np.argsort(d_raw)), ("原始-余弦", np.argsort(-c_raw)),
                    ("标准化-欧氏", np.argsort(d_std)), ("标准化-余弦", np.argsort(-c_std))]:
    idx = rest[order[:5]]
    print(f" {name} 前5近邻编号 {idx}  品种 {y[idx]}")
print(" 原始特征余弦相似度最小值 =", round(c_raw.min(), 4))

def loo_1nn(F, metric):
    hit = 0
    for i in range(len(F)):
        others = np.delete(np.arange(len(F)), i)
        if metric == "euc":
            j = others[np.argmin(norm(F[others] - F[i], axis=1))]
        else:
            j = others[np.argmax(cosine_similarity([F[i]], F[others])[0])]
        hit += y[j] == y[i]
    return hit / len(F)
```

其中 `norm = np.linalg.norm`。实测结果：

```text

 原始-余弦 前5近邻编号 [56 44 36 28 54]  品种 [0 0 0 0 0]
 标准化-欧氏 前5近邻编号 [20 56 40 54  7]  品种 [0 0 0 0 0]
 标准化-余弦 前5近邻编号 [20 56 40 54  3]  品种 [0 0 0 0 0]

 留一法 1-NN 准确率 原始：欧氏 0.7697  余弦 0.8483
 留一法 1-NN 准确率 标准化：欧氏 0.9551  余弦 0.9438
```

解读：

- （1）第 0 瓶酒的近邻在四种做法下都是品种 0，但具体是哪几瓶差别很大。原始特征下的两份名单几乎不重合；标准化之后，欧氏和余弦的前四名完全相同。
- （2）原始特征下，第 0 瓶酒和其余 177 瓶的余弦相似度**最小也有 0.9817**。原因在 10.3 节：每瓶酒的箭几乎都朝着"脯氨酸"方向，所有的箭挤在一个很窄的锥形里，彼此夹角都很小。这时余弦相似度几乎分不出谁是谁。
- （3）原始特征下余弦（84.8%）比欧氏（77.0%）好一些，部分原因是余弦不看长度，削弱了脯氨酸绝对数值的支配；但两者都远不如标准化以后（95.5% 和 94.4%）。**先把尺度理顺，比挑哪把尺子更要紧。** 标准化后两种度量相差不大，这次欧氏略好。

**11. 解：**

（1）程序核对：

```text
 cos(A,B) = 0.9935  cos(A,C) = 0.593
 欧氏 A-B = 3.4641  A-C = 7.0
```

两种方法都认为 B 更像 A：欧氏距离 3.46 小于 7.0，余弦 0.99 大于 0.59。

（2）评分都是 1—5 的正数，所有向量都落在"全为正"的那个角落里，彼此夹角不可能超过 90°，余弦自然都是正的。C 和 A 恰好相反的口味，被"大家都打正分"这件事掩盖了。

改进办法：先减去每个用户自己的平均分（**中心化**），让"高于自己平均"为正、"低于自己平均"为负，再算余弦：

```text
 中心化后 cos(A,B) = 0.9656  cos(A,C) = -0.7625
 皮尔逊 r(A,B) = 0.9656
```

中心化后，C 与 A 的余弦变成了 −0.76，反向的口味显露出来。同时，"打分偏低"这种整体偏移也被消掉了。程序还显示，中心化后的余弦恰好等于第8讲的皮尔逊相关系数 $r$：**相关系数，就是两组数各自减去平均值以后的夹角余弦。** 第60讲的推荐系统还会遇到"每个用户打分尺度不同"的问题。
