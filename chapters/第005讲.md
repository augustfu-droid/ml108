## 导语

很多人学写字，是从一本描红字帖开始的。纸上印着浅红色的字，你拿起笔，顺着红色的笔画一笔一笔地描。描的时候不用懂什么叫"结构"、什么叫"笔势"，只要描得像。描上几十页，红字越印越淡，最后只剩一个空格子，让你自己写。

## 5.1　研墨铺纸：准备环境

### Python 是什么

Python 是一门编程语言，由荷兰程序员吉多·范罗苏姆（Guido van Rossum）设计，1991 年首次公开发布。它的语法接近英语，缩进就是结构，读起来像伪代码，所以特别适合初学者。更重要的是，机器学习领域最常用的工具，NumPy（第6讲）、Pandas（第7讲）、Matplotlib（第8讲）、scikit-learn（第9讲）、PyTorch（第76讲），几乎都以 Python 为主要接口。学会 Python，等于拿到了进入这一整套工具箱的钥匙。

写 Python，需要一个**解释器**（interpreter）：它读你写的代码，一行一行地执行。你写的是文字，解释器把它变成计算机的动作。

### Anaconda：一次装好

对零基础的同学，最省事的办法是安装 **Anaconda**。它是一个 Python 的"发行版"：除了 Python 解释器本身，还打包了数百个科学计算常用的库，以及一个叫 **conda** 的包管理工具。装好 Anaconda，NumPy、Pandas、Matplotlib、scikit-learn、Jupyter 基本都已经在里面了，不用一个一个地装。

安装时注意三点：

1. 到 Anaconda 官网下载与自己操作系统（Windows / macOS / Linux）对应的安装包，选 Python 3 的版本；
2. 安装路径里最好不要有中文和空格，可以避免很多莫名其妙的问题；
3. 装完之后，打开"终端"（Windows 上是 Anaconda Prompt），输入 `python --version`，能看到版本号就说明装好了。

如果你已经熟悉命令行，也可以只装官方 Python，再用 `pip install` 按需安装各个库。两条路都行，殊途同归。本课程的代码在 Python 3.11 下运行验证。

### Jupyter：一边写，一边看

**Jupyter Notebook**（以及它的新版界面 JupyterLab）是一个在浏览器里写代码的笔记本。在终端输入 `jupyter notebook` 或 `jupyter lab`，浏览器会自动打开一个页面。

它的基本单位叫**单元格**（cell）。你在单元格里写几行代码，按 `Shift + Enter`，结果就直接显示在单元格下方。改一个数字，再按一次，马上看到新结果。单元格还可以写文字和公式，所以一个笔记本既是代码，也是实验记录。

这种"写一点、看一点"的方式，特别适合学习和做数据分析。等到程序写长了、要反复运行了，再把代码存成 `.py` 文件，用 `python 文件名.py` 运行。本课程的验证脚本都放在 `code/` 目录下，比如本讲的 `code/l005_basics.py`。

### 第一笔

不管用哪种方式，第一行代码都是这一句：

```python
print("你好，墨点")
```

运行结果：

```text
你好，墨点
```

`print` 是一个**函数**（function），作用是把括号里的东西显示出来。引号里的文字叫**字符串**。这一讲后面所有的"运行结果"，都是 `print` 打印出来的。

## 5.2　变量与类型：给数据起个名字

### 变量是一张标签

```python
n = 6
price = 9.9
name = "鸢尾花"
is_red = True
print(type(n), type(price), type(name), type(is_red))
```

运行结果：

```text
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>
```

`n = 6` 的意思是：**把名字 `n` 贴在数值 6 上**。这里的等号不是数学里的"相等"，而是"赋值"（assignment）：右边算出一个值，左边的名字指向它。所以 `n = n + 1` 在 Python 里完全合法，意思是"把 `n` 现在的值加 1，再让 `n` 指向新值"。

这个名字叫**变量**（variable）。变量名可以用字母、数字、下划线，不能以数字开头，区分大小写。好的变量名让代码自己会说话：`price` 比 `p` 好，`is_red` 比 `flag` 好。

### 四种基本类型

`type()` 告诉我们一个值是什么**类型**（type）。最基本的四种：

| 类型 | 英文 | 含义 | 例子 |
|---|---|---|---|
| 整数 | int（integer） | 没有小数部分的数 | `6`、`-3`、`2026` |
| 浮点数 | float | 带小数的数 | `9.9`、`0.05`、`3.0` |
| 字符串 | str（string） | 一段文字，用引号括起来 | `"鸢尾花"`、`'A'` |
| 布尔值 | bool（boolean） | 只有真、假两个值 | `True`、`False` |

机器学习里，特征多半是 float，类别标签可能是 int 或 str，"是否违约""是否垃圾邮件"这类判断是 bool。第2讲说过，数据到了模型手里都要变成数；类型，就是"这是一种什么样的数"。

### 类型转换与一个小意外

```python
print(int("42") + 1, float("3.5"), str(108) + "讲", int(3.9))
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2) == 0.3)
```

运行结果：

```text
43 3.5 108讲 3
0.30000000000000004
True
```

几点值得注意：

- `int("42")` 把字符串变成整数，才能参与加法；`str(108)` 把整数变成字符串，才能和"讲"拼在一起。**类型不同的东西不能随便混用**，`"108" + 1` 会报错。
- `int(3.9)` 得到 3，不是 4。它是**直接截掉小数部分**，不是四舍五入。
- `0.1 + 0.2` 不等于 0.3，而是 0.30000000000000004。这不是 Python 的错：计算机用二进制存小数，0.1 在二进制里是一个无限循环小数，存进去时只能近似。**比较两个浮点数是否相等，不要直接用 `==`**，先取整到合适的位数，或者看两者之差是否足够小。

### 字符串也是一串"格子"

```python
word = "墨点成星"
print(len(word), word[0], word[-1], word[:2], "墨点" + "成星", "墨" * 3)
```

运行结果：

```text
4 墨 星 墨点 墨点成星 墨墨墨
```

`len()` 求长度；`word[0]` 取第一个字，`word[-1]` 取最后一个字；`word[:2]` 取前两个字；`+` 拼接，`*` 重复。这里的方括号取值方式叫**索引**和**切片**，下面讲列表时会细说，字符串和列表用的是同一套规则。

## 5.3　运算与 f-string：让数算起来，让结果好看

### 算术、比较与逻辑

```python
print(7 + 2, 7 - 2, 7 * 2, 7 / 2, 7 // 2, 7 % 2, 2 ** 10)
print(3 > 2, 3 == 3.0, 3 != 3, (3 > 2) and (2 > 5), not True)
```

运行结果：

```text
9 5 14 3.5 3 1 1024
True True False False False
```

| 运算符 | 含义 | 例子 → 结果 |
|---|---|---|
| `+` `-` `*` | 加、减、乘 | `7 * 2` → 14 |
| `/` | 除法，结果**总是 float** | `7 / 2` → 3.5 |
| `//` | 整除，只要商 | `7 // 2` → 3 |
| `%` | 取余，只要余数 | `7 % 2` → 1 |
| `**` | 乘方 | `2 ** 10` → 1024 |
| `==` `!=` | 等于、不等于 | `3 == 3.0` → True |
| `>` `<` `>=` `<=` | 大小比较 | `3 > 2` → True |
| `and` `or` `not` | 并且、或者、取反 | `not True` → False |

两个容易混的地方：**一个等号 `=` 是赋值，两个等号 `==` 是比较**；`3 == 3.0` 是 True，因为数值相等，类型不同也不要紧。比较和逻辑运算的结果都是 bool，它们是后面 `if` 判断的原料。

### 复利：第一个公式

把本金 $P$ 存入银行，年利率为 $r$，每年的利息都滚进本金，$n$ 年后的本息合计是：

$$
A = P\,(1 + r)^{n}
$$

这里 $P$ 是本金（principal），$r$ 是年利率（rate），$n$ 是年数，$A$ 是到期金额（amount）。每过一年，钱都乘上一个 $(1+r)$，乘 $n$ 次就是 $(1+r)^n$。

那么，钱翻一倍要多少年？令 $A = 2P$：

$$
2P = P\,(1 + r)^{n} \;\Longrightarrow\; (1+r)^{n} = 2 \;\Longrightarrow\; n = \frac{\ln 2}{\ln (1 + r)}
$$

$\ln$ 读作"自然对数"，是以 $e \approx 2.718$ 为底的对数。对等式两边同时取对数，指数 $n$ 就"落"了下来，这是解指数方程的标准办法。

**纸笔例题 1**：本金 10000 元，年利率 5%。（1）两年后本息多少？（2）大约多少年翻倍？

解：（1）第一年后 $10000 \times 1.05 = 10500$ 元；第二年后 $10500 \times 1.05 = 11025$ 元，即 $10000 \times 1.05^2 = 11025$ 元。

（2）$\ln 2 \approx 0.6931$，$\ln 1.05 \approx 0.0488$，

$$
n = \frac{0.6931}{0.0488} \approx 14.2 \text{ 年}
$$

民间有个"72 法则"：翻倍年数约等于 72 除以利率的百分数，$72 / 5 = 14.4$，和精确值很接近。

### f-string：把数字嵌进句子

用 Python 来算，并把结果写成一句人话：

```python
import math
P, r, years = 10000, 0.05, 10
A = P * (1 + r) ** years
print(f"本金 {P} 元，年利率 {r:.0%}，{years} 年后本息 {A:.2f} 元")
print(f"翻倍年数 ln2/ln(1+r) = {math.log(2) / math.log(1 + r):.4f}")
print(f"{math.pi:.2f}|{0.953:.1%}|{1234567:,}|{7:>3}|")
```

运行结果：

```text
本金 10000 元，年利率 5%，10 年后本息 16288.95 元
翻倍年数 ln2/ln(1+r) = 14.2067
3.14|95.3%|1,234,567|  7|
```

字符串前面加一个 `f`，就成了 **f-string**（格式化字符串）：花括号 `{}` 里可以放变量甚至表达式，运行时会被替换成它的值。冒号后面是格式说明：

| 写法 | 含义 | 结果 |
|---|---|---|
| `{A:.2f}` | 保留 2 位小数 | `16288.95` |
| `{r:.0%}` | 写成百分数，0 位小数 | `5%` |
| `{0.953:.1%}` | 百分数，1 位小数 | `95.3%` |
| `{1234567:,}` | 千位分隔符 | `1,234,567` |
| `{7:>3}` | 右对齐，占 3 格 | `  7` |

`P, r, years = 10000, 0.05, 10` 是一次给三个变量赋值；`math.log` 是自然对数，来自 `math` 模块，`import` 的用法在 5.7 节再讲。以后汇报模型的准确率、误差，都会用 f-string 把数字排得整整齐齐。

## 5.4　列表：一行格子

### 索引从 0 开始

一个班 6 个人的成绩，用**列表**（list）装起来：

```python
scores = [78, 92, 65, 88, 95, 71]
print(scores[0], scores[2], scores[-1])
print(scores[1:4], scores[:3], scores[-2:], scores[::2])
```

运行结果：

```text
78 65 71
[92, 65, 88] [78, 92, 65] [95, 71] [78, 65, 95]
```

列表用方括号写，元素之间用逗号隔开。可以把它想成字帖上的一行格子，每个格子有一个编号，这个编号叫**索引**（index）。

**Python 的索引从 0 开始**：`scores[0]` 是第一个元素 78，`scores[2]` 是第三个元素 65。负数索引从末尾往前数：`scores[-1]` 是最后一个 71。

| 位置 | 第1个 | 第2个 | 第3个 | 第4个 | 第5个 | 第6个 |
|---|---|---|---|---|---|---|
| 元素 | 78 | 92 | 65 | 88 | 95 | 71 |
| 正索引 | 0 | 1 | 2 | 3 | 4 | 5 |
| 负索引 | −6 | −5 | −4 | −3 | −2 | −1 |

### 切片：左闭右开

`scores[a:b]` 叫**切片**（slice），取出索引从 `a` 到 `b-1` 的元素，**包含左端，不包含右端**。

- `scores[1:4]`：索引 1、2、3，即 `[92, 65, 88]`，一共 $4 - 1 = 3$ 个；
- `scores[:3]`：省略起点表示从头开始，前 3 个；
- `scores[-2:]`：省略终点表示一直到末尾，最后 2 个；
- `scores[::2]`：第三个数是步长，每隔一个取一个，得到索引 0、2、4。

"左闭右开"初看别扭，好处是：`[:3]` 和 `[3:]` 正好把列表一刀切成两段，不重不漏；切片长度就是两个端点相减。第2讲把数据切成训练集和测试集，本质上就是这样的一刀。

### 增删与常用函数

```python
scores.append(84)
print(scores, len(scores))
scores.pop()
print(len(scores), sum(scores), max(scores), min(scores))
print(sorted(scores), sorted(scores, reverse=True))
mixed = ["A", (1, 1), "红", 2.83]
print(mixed[1], len(mixed))
```

运行结果：

```text
[78, 92, 65, 88, 95, 71, 84] 7
6 489 95 65
[65, 71, 78, 88, 92, 95] [95, 92, 88, 78, 71, 65]
(1, 1) 4
```

- `append` 在末尾加一个元素，`pop` 把最后一个取走。列表是**可变的**，可以随时增删改。
- `len` 求个数，`sum` 求和，`max` / `min` 求最大最小。
- `sorted` 返回一个排好序的**新列表**，原列表不变；`reverse=True` 表示从大到小。
- 列表里可以混装不同类型的东西。`(1, 1)` 用圆括号写，叫**元组**（tuple），和列表很像，但创建之后不能修改，适合表示一个点的坐标这类"一组固定的数"。

## 5.5　字典：按名字查

### 键与值

列表按位置查，第几个；**字典**（dict，dictionary）按名字查。第1讲的训练点 A，有名字、坐标、类别三项信息，用字典装最清楚：

```python
point = {"name": "A", "x": (1, 1), "label": "红"}
print(point["label"], point.get("color"), point.get("color", "未知"))
point["label"] = "蓝"
print(point)
```

运行结果：

```text
红 None 未知
{'name': 'A', 'x': (1, 1), 'label': '蓝'}
```

字典用花括号写，里面是一对一对的 `键: 值`。冒号左边的叫**键**（key），像一张挂牌；右边的叫**值**（value），是挂牌下面挂的东西。

- `point["label"]` 用键取值，得到 "红"；
- `point["label"] = "蓝"` 改写一个键的值；若键不存在，就是新增一项；
- 用方括号取一个**不存在**的键，程序会报错（`KeyError`）；而 `get` 方法不会报错，找不到就返回 `None`（Python 里表示"什么都没有"的特殊值），或者返回你指定的默认值，比如 `"未知"`。

### 用 get 计数：最常用的一招

数一段话里每个词出现了几次，是字典最经典的用法：

```python
text = "数据 决定 上限 模型 逼近 上限"
cnt = {}
for w in text.split():
    cnt[w] = cnt.get(w, 0) + 1
print(cnt)
print(max(cnt, key=cnt.get))
for k, v in cnt.items():
    if v > 1:
        print(k, v)
```

运行结果：

```text
{'数据': 1, '决定': 1, '上限': 2, '模型': 1, '逼近': 1}
上限
上限 2
```

`text.split()` 按空格把句子切成一个词的列表。`for` 循环（下一节细讲）依次取出每个词 `w`，然后：

$$
\texttt{cnt[w]} \leftarrow \texttt{cnt.get(w, 0)} + 1
$$

这一行的意思是："这个词原来记了几次？没记过就当 0 次。加 1，再记回去。"第一次遇到"上限"，`get` 返回 0，记成 1；第二次遇到，返回 1，记成 2。

`max(cnt, key=cnt.get)` 找出出现次数最多的那个词：`key=` 告诉 `max` "按什么比大小"，这里按每个键对应的值比。`cnt.items()` 同时取出每一对键和值。

第2讲的词袋模型，就是这样数出来的；本讲最后 K 近邻的"投票"，也是这一招。

### 列表还是字典？

| | 列表 | 字典 |
|---|---|---|
| 怎么查 | 按位置（第几个） | 按名字（键） |
| 写法 | `[78, 92, 65]` | `{"name": "A", "label": "红"}` |
| 适合 | 一串同类的东西，顺序有意义 | 一个对象的多项属性；计数、查表 |

两者经常组合使用：**一个列表，里面每个元素是一个字典**，就是一张最朴素的数据表，每个字典是一行，每个键是一列。第7讲的 Pandas，就是把这种结构做成了专业工具。

## 5.6　控制流：判断与重复

到目前为止，代码都是从上到下一行一行执行的。**控制流**（control flow）让程序能做判断、能重复。

### if：分岔路口

给每个成绩评个等级：

```python
for s in scores:
    if s >= 90:
        level = "优"
    elif s >= 75:
        level = "良"
    else:
        level = "需努力"
    print(s, level)
```

运行结果：

```text
78 良
92 优
65 需努力
88 良
95 优
71 需努力
```

`if` 后面跟一个条件，条件为 True 就执行下面缩进的代码；`elif`（else if 的缩写）是"否则，如果"；`else` 是"以上都不满足"。**从上到下依次检查，第一个满足的分支执行完就结束**。所以 92 先满足 `s >= 90`，判为"优"，不会再去看 `s >= 75`。

注意两个语法细节：条件后面有一个**冒号**；属于这个分支的代码要**缩进**（通常是 4 个空格）。Python 不用花括号，缩进就是结构。缩进错了，程序要么报错，要么做的事情和你想的不一样。

### for：一遍一遍地临

`for` 循环依次取出一组东西中的每一个，对它做同样的事。上面的 `for s in scores` 就是：把 `scores` 里的成绩一个一个取出来，放进 `s`，执行一遍缩进的代码。

```python
total = 0
for i in range(1, 101):
    total += i
print("1 到 100 的和：", total)
```

运行结果：

```text
1 到 100 的和： 5050
```

`range(1, 101)` 生成从 1 到 100 的整数，同样是左闭右开，不含 101。`total += i` 是 `total = total + i` 的简写。累加器先设成 0，每转一圈加一个数，这个"先初始化、再循环累加"的套路，后面写损失函数、写训练循环，会用上无数次。

### while：洗到水清为止

`for` 适合"次数事先知道"的重复；如果只知道"什么时候停"，就用 `while`。回到复利问题：存 10000 元、年利率 5%，第几年余额首次超过 20000 元？

```python
balance, y = 10000, 0
while balance < 20000:
    balance *= 1.05
    y += 1
print(f"第 {y} 年首次翻倍，余额 {balance:.2f}")
print(f"第 14 年余额 {10000 * 1.05 ** 14:.2f}")
```

运行结果：

```text
第 15 年首次翻倍，余额 20789.28
第 14 年余额 19799.32
```

`while` 后面的条件只要为 True，就一直重复。每转一圈，余额乘 1.05，年数加 1；余额一旦达到 20000，条件变成 False，循环结束。

这和 5.3 节的公式 $n \approx 14.2$ 并不矛盾：公式给的是连续的"14.2 年"，而银行按整年结息，第 14 年末还差一点（19799.32 元），**第 15 年末才真正翻倍**。一个是数学上的精确解，一个是按规则一步一步模拟出来的结果，两者互相印证。

使用 `while` 要当心：如果条件永远为 True，循环就停不下来，这叫**死循环**。在 Jupyter 里遇到了，点工具栏上的"中断"按钮即可。

## 5.7　函数：写一次，用很多次

### def 与 return

同样的计算要做很多次，就把它打包成一个**函数**。下面三个函数分别计算平均数、方差和标准差：

```python
def mean(xs):
    return sum(xs) / len(xs)


def variance(xs):
    m = mean(xs)
    total = 0
    for x in xs:
        total += (x - m) ** 2
    return total / len(xs)


def std(xs):
    return math.sqrt(variance(xs))


print(f"平均分 {mean(scores):.2f}，方差 {variance(scores):.2f}，标准差 {std(scores):.2f}")
small = [2, 4, 4, 4, 5, 5, 7, 9]
print(mean(small), variance(small), std(small))
```

运行结果：

```text
平均分 81.50，方差 121.58，标准差 11.03
5.0 4.0 2.0
```

`def` 开头定义函数，后面是函数名和括号里的**参数**（parameter）；`return` 把结果交回给调用的地方。定义只是"写好范字"，不会执行；`mean(scores)` 这样**调用**时，`xs` 才指向 `scores`，函数体才真正运行。

注意 `variance` 里调用了 `mean`，`std` 里又调用了 `variance`：**函数可以一层一层地搭起来**，每一层只管一件事。

### 三个统计公式

函数背后是这三个公式。设有 $n$ 个数 $x_1, x_2, \dots, x_n$，$x_i$ 读作"x 下标 i"，表示其中第 $i$ 个数。

**平均数**（mean）：

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
$$

$\bar{x}$ 读作"x 拔"，表示平均数。$\sum$ 读作"西格玛"，是求和符号：$\sum_{i=1}^{n} x_i$ 表示让 $i$ 从 1 走到 $n$，把所有 $x_i$ 加起来。它对应的正是一个 `for` 循环，或者 `sum()`。

**方差**（variance）：

$$
\sigma^2 = \frac{1}{n}\sum_{i=1}^{n} \left(x_i - \bar{x}\right)^2
$$

$\sigma$ 是希腊字母，读作"西格玛"（小写），$\sigma^2$ 就是方差。它衡量数据的"分散程度"：每个数离平均数多远，先平方（去掉正负号，并放大离得远的），再求平均。

**标准差**（standard deviation）：

$$
\sigma = \sqrt{\sigma^2}
$$

方差是"平方后的单位"，开根号之后，标准差和原数据单位一致，可以直接说"成绩大约在平均分上下 11 分的范围内波动"。

对照一下代码：`variance` 里的 `for` 循环就是 $\sum$，`(x - m) ** 2` 就是 $(x_i-\bar{x})^2$，最后除以 `len(xs)` 就是 $\frac{1}{n}$。**公式和代码一一对应，这是本课程反复要练的基本功。**

> 说明：这里除以的是 $n$，称为**总体方差**。统计学里还常用除以 $n-1$ 的**样本方差**，两者的区别和 Pandas、NumPy 的默认口径，留到第7讲细说。

**纸笔例题 2**：求 $2, 4, 4, 4, 5, 5, 7, 9$ 的平均数、方差和标准差。

解：$n = 8$。

（1）平均数：$\bar{x} = \dfrac{2+4+4+4+5+5+7+9}{8} = \dfrac{40}{8} = 5$。

（2）每个数减去平均数：$-3, -1, -1, -1, 0, 0, 2, 4$；

平方：$9, 1, 1, 1, 0, 0, 4, 16$，求和为 $32$；

方差：$\sigma^2 = \dfrac{32}{8} = 4$。

（3）标准差：$\sigma = \sqrt{4} = 2$。

和程序输出的 `5.0 4.0 2.0` 完全一致。

## 5.8　动手：用纯 Python 写一个 K 近邻

现在把所有笔画合在一起。回顾第1讲的手算例题：平面上五个训练点，A(1,1) 红、B(2,2) 红、C(3,4) 蓝、D(5,5) 蓝、E(1,3) 红；新来一个点 Q(3,3)，问它是红还是蓝。K 近邻的做法是：

1. 算出 Q 到每个训练点的距离；
2. 按距离从近到远排序，取最近的 $K$ 个；
3. 这 $K$ 个点投票，票多的类别就是答案。

### 欧氏距离

两点 $\boldsymbol{a} = (a_1, a_2, \dots, a_m)$ 和 $\boldsymbol{b} = (b_1, b_2, \dots, b_m)$ 之间的**欧氏距离**（Euclidean distance）是：

$$
d(\boldsymbol{a}, \boldsymbol{b}) = \sqrt{\sum_{j=1}^{m} \left(a_j - b_j\right)^2}
$$

这里 $\boldsymbol{a}$、$\boldsymbol{b}$ 用粗体，表示它们是**向量**（一组有顺序的数），$m$ 是维数（特征个数），$a_j$ 是 $\boldsymbol{a}$ 的第 $j$ 个坐标。二维时就是勾股定理：横向差的平方加纵向差的平方，再开根号。例如 Q(3,3) 到 A(1,1)：

$$
d = \sqrt{(3-1)^2 + (3-1)^2} = \sqrt{8} \approx 2.83
$$

### 代码

完整代码（`code/l005_knn.py`）只用到本讲学过的东西：列表、字典、函数、`for`、`zip`、`sorted`、`math`。

```python
import math

# 第1讲的五个训练点：每个点是一个字典
points = [
    {"name": "A", "x": (1, 1), "label": "红"},
    {"name": "B", "x": (2, 2), "label": "红"},
    {"name": "C", "x": (3, 4), "label": "蓝"},
    {"name": "D", "x": (5, 5), "label": "蓝"},
    {"name": "E", "x": (1, 3), "label": "红"},
]


def distance(a, b):
    """欧氏距离：对应坐标相减、平方、求和、开根号"""
    total = 0
    for ai, bi in zip(a, b):
        total += (ai - bi) ** 2
    return math.sqrt(total)


def knn_predict(points, q, k):
    ranked = sorted(points, key=lambda p: distance(p["x"], q))
    votes = {}
    for p in ranked[:k]:
        votes[p["label"]] = votes.get(p["label"], 0) + 1
    return max(votes, key=votes.get), votes


q = (3, 3)
print("到 Q(3,3) 的距离，从近到远：")
for p in sorted(points, key=lambda p: distance(p["x"], q)):
    print(p["name"], p["label"], f"{distance(p['x'], q):.2f}")

for k in [1, 3]:
    label, votes = knn_predict(points, q, k)
    print(f"K = {k}：判为{label}，票数 {votes}")

print("-- 两个陷阱 --")
for k in [2, 4]:
    label, votes = knn_predict(points, q, k)
    print(f"K = {k}：判为{label}，票数 {votes}")

swapped = points[3:4] + points[:3] + points[4:]
print("把 D 挪到最前面：", [p["name"] for p in swapped])
label, votes = knn_predict(swapped, q, 4)
print(f"K = 4：判为{label}，票数 {votes}")
```

运行结果：

```text
到 Q(3,3) 的距离，从近到远：
C 蓝 1.00
B 红 1.41
E 红 2.00
A 红 2.83
D 蓝 2.83
K = 1：判为蓝，票数 {'蓝': 1}
K = 3：判为红，票数 {'蓝': 1, '红': 2}
-- 两个陷阱 --
K = 2：判为蓝，票数 {'蓝': 1, '红': 1}
K = 4：判为红，票数 {'蓝': 1, '红': 3}
把 D 挪到最前面： ['D', 'A', 'B', 'C', 'E']
K = 4：判为蓝，票数 {'蓝': 2, '红': 2}
```

### 逐行解读

**数据结构**：五个点装在一个列表里，每个点是一个字典，坐标用元组。这正是 5.5 节说的"列表套字典"的小数据表。

**`distance`**：`zip(a, b)` 把两点的坐标一一配对，循环里对每一对"相减、平方、累加"，最后开根号。它对任意维数都成立：二维的点、十三维的葡萄酒样本，都是这几行。

**`knn_predict`** 只有四行，却是整个算法：

- `sorted(points, key=lambda p: distance(p["x"], q))`：按"到 Q 的距离"给所有训练点排队，对应第 1、2 步；
- `ranked[:k]`：切片取最近的 $K$ 个；
- `votes.get(...) + 1`：5.5 节的计数招式，对应第 3 步投票；
- `max(votes, key=votes.get)`：票数最多的类别。

**结果**：距离表和第1讲手算的完全一致：C 最近（1.00），然后是 B（1.41）、E（2.00），A 和 D 并列最远（都是 $\sqrt{8} \approx 2.83$）。$K = 1$ 时只看 C，判为蓝；$K = 3$ 时看 C、B、E，一蓝两红，判为红。**同一个点，K 不同，答案就不同**，这是第1讲留下的问题，现在由程序亲手复现。

### 两个陷阱

后半段输出，揭开了两个写 K 近邻时一定会遇到的坑。

**陷阱一：平票。** $K = 2$ 时，最近的两个点 C 蓝、B 红，一比一。程序判为"蓝"，并不是因为蓝更有道理，而是因为字典会记住键插入的先后顺序，`max` 遇到并列时返回最先出现的那个，而 C 离得最近、最先投票。**二分类时 K 取奇数，就能避免平票。**

**陷阱二：距离相同，谁先谁后？** A 和 D 到 Q 的距离都是 2.83。$K = 4$ 时，第四名只能取一个。Python 的 `sorted` 是**稳定排序**：距离相同的元素，保持原来的先后顺序。原列表里 A 在 D 前面，所以第四名是 A，三红一蓝，判为红；把 D 挪到列表最前面，第四名就变成 D，两红两蓝平票，又判成了蓝。

**数据的排列顺序本不该影响答案，却影响了。** 这类"边界情况"在真实数据里很常见。成熟的机器学习库也必须对平票、等距定下明确的规则；我们自己写一遍，才知道这些规则为什么必须存在。至于 K 到底取多少、要不要让近的邻居多算几票，第36讲的交叉验证和第37讲的 K 近邻专讲会回答。

### 预告：同样的计算，快几十倍

我们的 K 近邻每次只算一个点到一个点的距离，用的是 Python 的 `for` 循环。数据一多会怎样？`code/l005_numpy_preview.py` 生成一百万个随机点，分别用纯 Python 和 NumPy 计算它们到 Q 的距离：

```python
def by_loop():
    return [distance(p, q) for p in pts]


P = np.array(pts)
Q = np.array(q)


def by_numpy():
    return np.sqrt(((P - Q) ** 2).sum(axis=1))
```

本机一次运行的结果：

```text
一百万个点到 Q 的距离：纯 Python 0.310 秒；NumPy 11.7 毫秒；快约 26 倍
结果一致： True
```

计时会随机器和运行时刻波动，再运行一次得到的是"快约 27 倍"，数量级不变。`by_numpy` 里没有一个 `for`：**一百万个点的距离，一行算完，结果和循环完全一致。** 这只是一个查询点；如果同时有很多查询点、要算一整张距离矩阵，第6讲的本机实测快了约 126 倍。这一行是怎么做到的，正是下一讲的内容。

**9. 解：**

（1）$A = 5000 \times 1.08^{5}$。令 `P, r = 5000, 0.08`，实测 `f"{P * (1 + r) ** 5:.2f}"` 输出 `7346.64`，即约 7346.64 元。

（3）实测 $1.08^{9} = 1.9990$，还差一点不到 2；$1.08^{10} = 2.1589$，超过 2。所以按整年结息，**第 10 年末**首次翻倍。`while` 循环验证：

```python

    b *= 1 + r
    y += 1

```

**10. 参考代码：**

```python
def euclidean(a, b):
    return math.sqrt(sum((ai - bi) ** 2 for ai, bi in zip(a, b)))


def manhattan(a, b):
    return sum(abs(ai - bi) for ai, bi in zip(a, b))


def knn_predict(points, q, k, dist=euclidean):
    ranked = sorted(points, key=lambda p: dist(p["x"], q))
    votes = {}
    for p in ranked[:k]:
        votes[p["label"]] = votes.get(p["label"], 0) + 1
    return max(votes, key=votes.get), votes


for q in [(3, 3), (4, 4)]:
    for dist in [euclidean, manhattan]:
        print(q, dist.__name__, [p["name"] + ":" + str(round(dist(p["x"], q), 2))
                                 for p in sorted(points, key=lambda p: dist(p["x"], q))])
        for k in [1, 3, 5]:
            print("   K =", k, knn_predict(points, q, k, dist))
```

实测结果（`code/l005_exercises.py`）：

在这组小数据上，换用曼哈顿距离后，**距离的数值变了，排出来的先后顺序基本没变，预测结论完全相同**。但要注意：曼哈顿距离下 Q(3,3) 到 B、E 的距离都是 2，出现了新的并列，只是恰好没影响结果。

还有一个现象值得留意：$K = 5$ 时，两个查询点都判为红。因为五个训练点里三红两蓝，$K$ 取到全部训练点时，每个新点都只看"总体谁多"，模型就退化成了"永远猜多数类"，也就是第4讲说的基线。**$K$ 太小容易被个别点左右，$K$ 太大又什么都分不出来**，这正是第36讲要用交叉验证来权衡的问题。

函数可以像普通的值一样当作参数传来传去（`dist=euclidean`），`dist.__name__` 取出函数的名字，这是 Python 很灵活的一面。

**11. 参考：**

总距离次数：$10^6 \times 10^4 = 10^{10}$，即一百亿次。实测纯 Python 每一百万次约 0.310 秒，则约需

$$
\frac{10^{10}}{10^{6}} \times 0.310 = 3100 \text{ 秒} \approx 52 \text{ 分钟}
$$

快 26 倍约需 119 秒，两分钟左右；若像第6讲算距离矩阵那样快约 126 倍，约 25 秒（`code/l005_exercises.py` 实测换算）。

"不必全算"的思路，可以从这几个方向想：

- **建索引**：事先把训练点按空间位置分区（例如 KD 树、球树），查询时只检查附近几个区里的点；
- **近似最近邻**：允许找到的不是严格最近、而是"足够近"的邻居，换取几个数量级的速度，大规模检索系统常用这类方法；
- **减少训练点**：去掉冗余样本，或用每一类的少数代表点代替全部样本；
- **降维**：特征维数少了，每次距离计算也更便宜（主成分分析，第59讲）。

开放题，言之成理即可。核心是认识到：K 近邻"不训练"，代价是**每次预测都要面对全部训练数据**。
