# 第57讲　形状不规则的群：DBSCAN

> 核心看邻域里够不够数。散晶隔着盐埂。半径一到不了，它就是噪声。半径放到六，它进组，仍不是核心。

---

## 导语

盐田沿一条线铺开。五处卤池挨在一起，一粒散晶隔在盐埂外面。半径够不到盐埂的那一边，散晶就不进组。半径放到正好含住这段距离，散晶进组，可它自己的邻域仍然不够数，所以它不是核心。

这片盐田不是第14讲的梯田，盐埂不是那一讲的田埂。卤池不是第55讲的谷堆，也不把第56讲的支脉再并一次。散晶不是第35讲的尘。第35讲的噪声是尘的平方再取期望，纸笔里那一项是 $\dfrac{2}{3}$。本讲的噪声是密度够不到的点。那一项 $\dfrac{2}{3}$ 不重算，两个词不要并成一句。

第56讲的两棵树、距离 $1$、$2$、$\dfrac{5}{2}$、$\dfrac{11}{2}$ 留在那一讲。第55讲的场心不重算。本讲的六处是另一批位置。

六处写在一条线上。甲 $0$，乙 $1$，丙 $2$，丁 $3$，戊 $4$，己 $10$。己是盐埂外的散晶。戊到己的距离是 $6$。邻域含等于：距离正好等于半径，算在里面。最少点数把自己算进去。

三个葡萄品种本讲不用。不下载。种子写成 $57$，只用它打乱行序。轮廓系数留给第58讲。

这一讲回答五个问题：

1. 半径是 $1$、最少点数是 $3$ 时，谁是核心，谁只是挨着核心，谁是噪声？
2. 戊为什么从乙走得到，却不是从乙直接走来的？为什么从戊走不回乙？
3. 半径改成 $6$、最少点数仍是 $3$，己的归属为什么变了，又为什么仍不是核心？
4. 不改半径、不改最少点数时，这六处为什么全部是噪声？
5. 种子 $57$ 打乱行序以后，核心的集合为什么还是原来那几处？

## 57.1　邻域把自己算进去

密度聚类这一套，常被写成四个字母，屏幕上可以这么写。旁白不念这四个字母。半径记作 $\varepsilon$，$\varepsilon$ 读作「艾普西龙」。最少点数记作 $m$。本讲先把 $\varepsilon=1$、$m=3$ 算完，再把半径单独改成 $6$。$m$ 先不动。

点 $p$ 的邻域，是所有与 $p$ 的距离小于或等于 $\varepsilon$ 的点，包括 $p$ 自己：

$$
N(p)=\{q:\ |q-p|\le \varepsilon\}
$$

$|N(p)|$ 读作邻域个数。$p$ 是核心，当且仅当

$$
|N(p)|\ge m
$$

$m=3$ 时，核心至少要有三个，其中可以包括自己。若只数别人、不数自己，乙在半径 $1$ 上只有甲和丙两个邻居，就会被误判成不是核心。本讲把自己算进去，乙的个数是 $3$，是核心。

$q$ 从 $p$ 直接密度可达，要两件事同时成立：$p$ 是核心，并且 $q$ 在 $N(p)$ 里。只挨着一个非核心，不够。

$q$ 从 $p$ 密度可达，是有一条链 $p=p_1,p_2,\ldots,p_n=q$，每一步 $p_{i+1}$ 都从 $p_i$ 直接可达。链上除了最后一点，前面的点都得是核心，否则走不出下一步。因此可达不一定对称：边界点可以从核心走来，核心不必从边界点走回去。

两个边界点之间，谁也走不到谁，可它们可以都从同一个核心走来。这时说它们密度相连，同在一组。一组，就是一群两两密度相连的点。

进了组、自己又不是核心的，叫边界。哪一个核心都走不到的，叫噪声。噪声的组号本讲写成 $-1$。它不是第35讲那个 $\dfrac{2}{3}$。

## 57.2　半径一：乙丙丁是核心，己是噪声

半径 $1$，最少点数 $3$。六处的邻域个数：

| 点 | 位置 | 邻域里有谁 | 个数 | 核心 |
|---|---|---|---|---|
| 甲 | $0$ | 甲、乙 | $2$ | 不是 |
| 乙 | $1$ | 甲、乙、丙 | $3$ | 是 |
| 丙 | $2$ | 乙、丙、丁 | $3$ | 是 |
| 丁 | $3$ | 丙、丁、戊 | $3$ | 是 |
| 戊 | $4$ | 丁、戊 | $2$ | 不是 |
| 己 | $10$ | 己 | $1$ | 不是 |

甲到丙是 $2>1$，所以甲的邻域没有丙。戊到乙是 $3>1$，戊的邻域没有乙。己到戊是 $6>1$，己单独一个。

六处的邻域可以按距离逐个排除。甲在 $0$：到乙是 $1$，到丙是 $2$。$2>1$，丙以及更远的丁、戊、己都不在。邻域是甲、乙，个数 $2$。乙在 $1$：到甲是 $1$，到丙是 $1$，到丁是 $2$。$2>1$，丁被排除。邻域是甲、乙、丙，个数 $3$。丙在 $2$：到乙、丁都是 $1$，到甲是 $2$，到戊是 $2$。甲和戊都在外面。邻域是乙、丙、丁，个数 $3$。丁在 $3$：到丙、戊都是 $1$，到乙是 $2$，到己是 $7$。邻域是丙、丁、戊，个数 $3$。戊在 $4$：到丁是 $1$，到丙是 $2$，到己是 $6$。邻域是丁、戊，个数 $2$。己在 $10$：到戊已经是 $6$，邻域只有己，个数 $1$。

核心要个数大于或等于 $3$。乙、丙、丁是 $3$，正好够。甲、戊是 $2$，各少 $1$。己是 $1$，少 $2$。甲比乙少的那一个，就是丙：丙到乙是 $1$，到甲是 $2$。戊比丁少的那一个，就是丙：丙到丁是 $1$，到戊是 $2$。少的是同一处丙，落在链条的两端外面。

半径 $1$ 上，距离小于或等于 $1$ 的对，只有相邻的四对：甲乙、乙丙、丙丁、丁戊，每对距离都是 $1$。甲丙是 $2$，已经是两步，进不了邻域。个数等于自己再加上这几条边上的邻居。甲只有乙，再加自己，是 $2$。乙有甲和丙，再加自己，是 $3$。丙有乙和丁，是 $3$。丁有丙和戊，是 $3$。戊只有丁，是 $2$。己和戊之间是 $6$，一条边都没有，只剩自己，是 $1$。四条边各算两端，是 $8$ 个邻居位置，加上六处自己，是 $14$。个数 $2+3+3+3+2+1=14$。两种数法相同。核心就是有两条边的乙、丙、丁。端点甲和戊只有一条边，个数差 $1$。把最少点数改成 $4$ 时，乙还要再找一个邻居。下一位是丁，距离是 $2$。$2-1=1$，比半径大出整整一步，个数仍是 $3$，$4-3=1$。门槛加 $1$，要的那个人正好站在半径外面一步。半径放到 $6$ 以后，个数和从 $14$ 变成 $5+5+5+5+6+2=28$。多出来的 $28-14=14$，正好又是十四条端点，也就是前面那七条新边各算两端。半径 $1$ 的四条边，和半径 $6$ 新加的七条边，条数不同，端点的总数却都是 $14$。一个是原来就有的，一个是后来含进来的。

核心是乙、丙、丁。组号印成 `0 0 0 0 0 -1`。前五处在同一组，己的组号是 `-1`。

甲不是核心，可甲在乙的邻域里，乙是核心，所以甲从乙直接可达。甲是边界。

戊从丁直接可达：丁是核心，距离是 $1$，含等于，正好在邻域里。戊从乙不是直接可达，距离是 $3>1$。可链还在：乙是核心，走到丙；丙是核心，走到丁；丁是核心，走到戊。所以戊从乙密度可达，只是不直接。戊自己不是核心，从戊走不回乙：链的起点若不是核心，就没有下一步。可达不是来回同一条。

己从乙、丙、丁、戊都走不到。半径 $1$ 时它是噪声。

把链的下标再写一遍，免得和名字错位。甲是下标 $0$，乙是 $1$，丙是 $2$，丁是 $3$，戊是 $4$，己是 $5$。直接可达只看一步：从 $3$ 到 $4$，距离 $1$，而且 $3$ 是核心，所以戊从丁直接可达。从 $1$ 到 $4$，距离 $3>1$，不是一步。密度可达允许多步：从 $1$ 到 $2$，从 $2$ 到 $3$，从 $3$ 到 $4$。这三步的起点 $1$、$2$、$3$ 都是核心。所以戊从乙可达。反方向从 $4$ 出发，$4$ 不是核心，第一步就走不出，乙不能从戊走回。甲是下标 $0$，个数 $2$，不是核心，可它在下标 $1$ 的邻域里，所以甲是边界，组号仍是 $0$，不是 $-1$。边界和噪声的差别就在这一步：有没有一个核心把你算进邻域。

三步的距离都是 $1$：$|2-1|=1$，$|3-2|=1$，$|4-3|=1$。每一步都含等于，而且每一步的起点个数都是 $3$。直接那一步若硬从乙跳到戊，距离是 $|4-1|=3$。三步各长 $1$，加起来是 $3$。半径只够其中一步。另外两步是 $1+1=2$，所以直线距离比半径大 $2$，不能并成一步。

反方向即使先看戊到丁：距离仍是 $1$，丁也在戊的邻域里。可直接可达要求起点是核心。戊的个数是 $2$，小于 $3$，这一步的起点不合格。链在第一步就停。乙到戊的三步，和戊到乙的一步，用的是同一段距离 $1$，方向一换，资格就没了。

甲这一侧是同一件事的另一端。甲从乙直接可达：距离 $1$，乙的个数是 $3$。乙从甲不是直接可达：甲的个数是 $2$。甲到丙是 $2$，丙的邻域里没有甲，所以甲只能靠乙这一条边进组，不能靠丙。戊只能靠丁，不能靠丙，因为戊到丙是 $2$。两条端点各靠内侧那一个核心。己则连内侧的戊都靠不上，距离 $6$，所以组号是 $-1$，不是边界。

## 57.3　半径六：己进组，仍不是核心

只改半径，最少点数仍是 $3$。半径 $6$ 时的邻域个数：

| 点 | 个数 | 核心 |
|---|---|---|
| 甲 | $5$ | 是 |
| 乙 | $5$ | 是 |
| 丙 | $5$ | 是 |
| 丁 | $5$ | 是 |
| 戊 | $6$ | 是 |
| 己 | $2$ | 不是 |

甲到戊是 $4\le 6$，所以甲的邻域含进戊，不含己。己在 $10$。它到六处的距离是：

| 到 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 |
|---|---|---|---|---|---|---|
| 距离 | $10$ | $9$ | $8$ | $7$ | $6$ | $0$ |
| 半径 $6$ | 不在 | 不在 | 不在 | 不在 | 在 | 在 |

$10$、$9$、$8$、$7$ 都大于 $6$。只有戊的 $6$ 含等于，再加上己自己。所以己的个数是 $2$，不是把甲也算进来。戊到己是 $6$，含等于，戊的个数是 $6$，六处都在戊的邻域里。己的邻域只有戊和己，个数是 $2<3$，不是核心。

甲到戊的全长是 $4$，而 $4\le 6$。所以甲、乙、丙、丁、戊这五处，每一处的邻域都含得住另外四处。甲到己是 $10>6$，乙到己是 $9>6$，丙到己是 $8>6$，丁到己是 $7>6$。这四处的个数都是 $5$，不是 $6$。戊到己是 $6$，才把个数加成 $6$。己到丁、丙、乙、甲是 $7$、$8$、$9$、$10$，四份都大于 $6$，只留下戊和自己，个数是 $2$。

超出半径的部分是位置差再减去 $6$：

$$
10-6=4,\quad 9-6=3,\quad 8-6=2,\quad 7-6=1,\quad 6-6=0
$$

甲超出 $4$，乙超出 $3$，丙超出 $2$，丁超出 $1$，戊刚好是 $0$。这五份超出是 $4,3,2,1,0$，相加是 $10$。五份距离本身是 $10,9,8,7,6$，相加是 $40$。每份都先减掉半径 $6$，五份一共减掉 $30$，$40-30=10$，和超出的和相同。$0+1+2+3+4=10$。从戊到甲，超出半径的量正好是 $0,1,2,3,4$，一步多 $1$。己若再找一个邻居，下一位是丁，距离 $7$，比半径大 $1$。个数 $2$ 比最少点数 $3$ 少 $1$。少的这一个，就是丁。丁超出的 $1$，和个数少的 $1$，是同一处够不到。甲的 $10$ 更远，不能拿来补这个空位。半径 $1$ 时这五份超出用不上，因为门槛是 $1$，己到戊已经超出 $6-1=5$，五份距离全部在邻域外面。个数和只有 $14$，对得上四条长度为 $1$ 的边。半径 $6$ 才把超出 $0$ 的戊含进来，个数和变成 $28$。

戊的六份距离可以逐个减出来。戊在 $4$。到甲是 $|4-0|=4$，到乙是 $|4-1|=3$，到丙是 $|4-2|=2$，到丁是 $|4-3|=1$，到自己是 $0$，到己是 $|10-4|=6$。六份是 $4,3,2,1,0,6$，最大的一份正好是 $6$，所以六份都小于或等于半径，个数是 $6$。甲在 $0$，六份是 $0,1,2,3,4,10$。前五份都小于或等于 $6$，最后一份 $10$ 超出 $4$，个数是 $5$。乙在 $1$，到己是 $9$，其余五份是到甲、乙、丙、丁、戊，分别是 $1,0,1,2,3$，都小于或等于 $6$，个数仍是 $5$。丙到己是 $8$，丁到己是 $7$，各自把那一份排除以后，个数也是 $5$。个数从 $5$ 跳到 $6$，只发生在戊：到己的距离从丁的 $7$ 降到戊的 $6$，降的这 $1$ 让它跨过含等于。

己从甲密度可达，链可以写成甲、乙、丙、丁、戊、己。五步的距离是 $1,1,1,1,6$。相加

$$
1+1+1+1+6=10
$$

这 $10$ 就是甲到己的距离。直接看，$10>6$，一步不行。拆开以后，前四步都是 $1$，最后一步是 $6$，每一步都小于或等于半径。前五处在这个半径下都是核心，最后一点己可以不是核心。所以可达，仍然不是直接。半径 $1$ 时这条链走到戊就停：戊到己是 $6>1$，而且己的个数是 $1$，没有下一步。半径从 $1$ 改到 $6$，新接上的只有最后这一步。

半径 $1$ 时，甲从乙直接可达：乙是核心，距离 $1$。乙从甲不是直接可达：甲的个数是 $2$，起点不合格。半径改成 $6$ 以后，甲的个数是 $5$，已经是核心，甲到乙仍是 $1\le 6$，乙从甲变成直接可达。这一对的来回，在半径 $1$ 上是单行，在半径 $6$ 上是来回都走得通。己和戊不是这样。己从戊在半径 $6$ 上直接可达，因为戊的个数是 $6$。戊从己仍然不是：己的个数是 $2$。半径放开以后，甲乙那一对的不对称消失了，戊己这一对的不对称还在。进组的己，仍然不能当链的起点。

两个半径的个数差，可以按每人多出来的邻居来对。半径 $1$ 时，甲的个数是 $2$，只有邻居乙。半径 $6$ 时，甲再含进丙、丁、戊，距离是 $2$、$3$、$4$，三个人，$2+3=5$。乙原来个数 $3$，再含进丁和戊，距离 $2$ 和 $3$，是两个人，$3+2=5$。丙再含进甲和戊，距离都是 $2$，$3+2=5$。丁再含进甲和乙，距离 $3$ 和 $2$，$3+2=5$。戊原来个数 $2$，再含进甲、乙、丙、己，距离 $4$、$3$、$2$、$6$，四个人，$2+4=6$。己原来个数 $1$，只含进戊，$1+1=2$。甲乙丙丁都没有含进己，因为 $10$、$9$、$8$、$7$ 仍大于 $6$。

多出来的这些邻居，每条边数了两端。$3+2+2+2+4+1=14$，是十四条端点。$14/2=7$，是七条新边：甲丙、甲丁、甲戊、乙丁、乙戊、丙戊、戊己。半径 $1$ 原有四条边，甲乙、乙丙、丙丁、丁戊。$4+7=11$。另一头核对：甲到戊这五处两两都有边，$5\times 4/2=10$，再加戊己，也是 $11$。十一乘二是 $22$ 个邻居位置，加上六处自己，是 $28$。个数 $5+5+5+5+6+2=28$。两种数法相同。半径从 $1$ 放到 $6$，新含住的是这七条，不是把丁己的 $7$ 也收进来。

七条新边的距离分别是：$|2-0|=2$，$|3-0|=3$，$|4-0|=4$，$|3-1|=2$，$|4-1|=3$，$|4-2|=2$，$|10-4|=6$。七个数都小于或等于 $6$。仍被排除的四条是丁己 $|10-3|=7$、丙己 $|10-2|=8$、乙己 $|10-1|=9$、甲己 $|10-0|=10$。$7$ 只比 $6$ 大 $1$，是离门槛最近的那条被排除的边。戊己的 $6$ 和丁己的 $7$ 只差这 $1$，个数就从丁的 $5$ 变成戊的 $6$，己也因此只挂在戊上。

前五处里，位置写成 $x$，到己的距离是 $10-x$。$10-x\le 6$ 时，$x\ge 4$。甲乙丙丁的位置是 $0,1,2,3$，都小于 $4$，到己都大于 $6$，个数停在 $5$。戊的位置是 $4$，$10-4=6$，个数是 $5+1=6$。己自己的位置是 $10$，邻域里能进来的前五处只有 $x\ge 4$ 的戊，再加上自己，个数是 $2$。半径 $1$ 时这条规则用不上，因为门槛是 $1$，前五处里相邻才够得着，个数不是 $5$。两个半径，一个按一步的边来数，一个按 $10-x$ 与 $6$ 比大小。

组号变成 `0 0 0 0 0 0`。己的组号从 `-1` 变成 `0`。归属变了。

己从戊直接可达：戊在这个半径下是核心，距离 $6$ 含得住。己从丁不是直接可达，丁到己是 $7>6$。己从甲密度可达，因为甲已经是核心，链可以走到戊，再走到己。

反方向：戊从己不是直接可达。己不是核心，即使距离是 $6$，也不能从己出发把戊收成「从己直接可达」。进组，和不成为核心，是两件事。

甲和戊在半径 $1$ 时不是核心，半径 $6$ 时变成核心。他们的组号本来就是 $0$，组号没变，变的是身份。真正换了组号的是己：从噪声进到这一组，仍不是核心。

盐埂画在戊和己之间，不另设一个数据点。它只说明这段距离是 $6$。半径 $1$ 跨不过去，半径 $6$ 正好含住。

甲在半径 $6$ 时个数是 $5$，不是 $6$。己到甲是 $10$，十大于六，甲的邻域到戊为止，到不了己。戊的个数才是 $6$，因为 $10-4=6$，正好等于半径。己的个数是 $2$：戊，和己自己。$2$ 比最少点数 $3$ 少 $1$。少的这一处，不是把甲算进来就能补上。甲到己是 $10$，不在半径 $6$ 里。所以己进了组，组号是 $0$，核心那一行仍然没有己。图上的圆只标谁是核心，半径不按 $6$ 去画满，免得六这个数把整条盐田盖住。距离 $6$ 写在戊和己之间，不靠那个圆的大小。成片里散晶自己动，图只是底稿。不要把底稿整张停在画面上当镜头。线要在镜头里自己长出来。

## 57.4　默认会把六处都当成噪声

不写半径时，这一版是 $0.5$。不写最少点数时，是 $5$。相邻两处的距离是 $1$，已经大于 $0.5$，每一处的邻域只有自己，个数是 $1$。$1<5$，没有核心。没有核心，就没有人能把别人走成可达。六处的组号都是 `-1`，核心那一行是「无」。

$1-0.5=0.5$。最近的邻居比半径正好大出一个 $0.5$，所以含等于也够不着隔壁。个数 $1$ 比最少点数 $5$ 少 $4$，因为 $5-1=4$。半径 $1$、最少点数 $3$ 时，乙的个数是 $3$，正好够。默认这一对把半径收到 $0.5$、最少点数放到 $5$，两头一起离开那个正好够的位置。本讲的手算不用这一对默认。手算用半径 $1$ 与半径 $6$，最少点数都是 $3$。默认那一对只用来看见：半径和最少点数不写，结果可以全部变成噪声。

最少点数改成 $4$、半径仍是 $1$，也没有核心。半径 $1$ 时个数最多的是乙、丙、丁，都是 $3$，小于 $4$。六处又都是噪声。这是把最少点数换掉，不是把半径换掉。本讲正文的两个结果只换半径。最少点数换掉的这一组，放在习题里核对。库若按这一组去跑，组号是六个 `-1`，核心下标那一行是「无」。三个 $3$ 都差一，没有一处能到 $4$。不要把「差一」收成仍有核心。核心要个数大于或等于最少点数，不是大于或等于最少点数减一。

少掉的个数可以按人分开。乙、丙、丁的个数是 $3$，$4-3=1$，三处都差 $1$。甲和戊的个数是 $2$，$4-2=2$，各差 $2$。己的个数是 $1$，$4-1=3$，差 $3$。正文里最少点数是 $3$ 时，$3\ge 3$，乙丙丁正好够，甲和戊各差 $1$，己差 $2$。最少点数从 $3$ 加到 $4$，原来正好够的三处一起不够。组号从 `0 0 0 0 0 -1` 变成六个 `-1`。己本来就是 `-1`。变的是前五处：核心先没了，甲和戊也就没有核心可以走过来，边界跟着变成噪声。

种子 $57$ 把行序打成 `1 2 0 4 3 5`。半径 $1$ 时，按原顺序排回来的组号仍是 `0 0 0 0 0 -1`，核心仍是乙、丙、丁。半径 $6$ 时，组号仍是 `0 0 0 0 0 0`。核心按扫到的行序会写成乙、丙、甲、戊、丁，按甲到戊的原序写是甲、乙、丙、丁、戊。五处还是这五处，己仍不在核心里。这一例只有一组，边界不会被两组同时够到，所以行序没有把组号改掉。

这行序写成名字是乙、丙、甲、戊、丁、己。半径 $1$ 的核心只有乙、丙、丁。乙在打乱后的第一行，丙在第二行，丁在第五行，中间的甲和戊不是核心，所以按行序写出的核心仍是乙、丙、丁，和原序相同。半径 $6$ 的核心是除己以外的五处。按行序是乙、丙、甲、戊、丁，己留在最后而且个数是 $2$。按甲到戊的原序是甲、乙、丙、丁、戊。两个写法是同一个集合。集合相同，组号才不跟着行序改。

## 本讲小结

**7.** 错。半径 $6$ 时己的个数是 $2$，输出写着「己核心 不是」。组号变成 `0`，只说明进了组。

**8.** 个数：$2,3,3,3,2,1$。核心乙、丙、丁。边界是甲和戊：甲从乙直接可达，戊从丁直接可达。噪声是己。戊从乙要经过丙和丁，距离 $3$ 不是直接的一步。戊不是核心，链不能从戊出发，所以乙不能从戊走回。

甲的邻域到乙为止，因为甲到丙是 $2$。乙的邻域是甲、乙、丙，到丁是 $2$，个数 $3$，是核心。丙是乙、丙、丁。丁是丙、丁、戊。戊只有丁、戊，个数 $2$。己到戊是 $6$，个数 $1$。$3\ge 3$ 的只有乙丙丁。甲在乙的邻域里，戊在丁的邻域里，所以这两处是边界，组号是 $0$。己不在任何一个核心的邻域里，组号是 $-1$。

戊从乙的链是乙到丙、丙到丁、丁到戊，三步距离都是 $1$，三步的起点都是核心。乙到戊的直线距离是 $3$，$3-1=2$，不能当成直接的一步。反方向戊的个数是 $2$，起点不是核心，即便戊到丁的距离是 $1$，也不能从戊出发。

**9.** 戊的个数是 $6$，己的个数是 $2$。己在戊的邻域里，戊是核心，所以己从戊直接可达，组号从 `-1` 变成 `0`。己不是核心，戊不能从己直接走来。丁到己是 $10-3=7$，大于 $6$。

己到甲乙丙丁戊己的距离是 $10$、$9$、$8$、$7$、$6$、$0$。减去半径 $6$，超出是 $4$、$3$、$2$、$1$、$0$，自己是 $0$。只有戊和己落在邻域里，个数 $2$。$2<3$，己不是核心。戊到这六处的距离都不大于 $6$，个数 $6$，戊是核心，所以己从戊直接可达。丁到己是 $7$，$7-6=1$，直接走不到。己不是核心，距离即使等于 $6$，戊也不能从己直接走来。组号变成 $0$，核心那一行仍没有己。

从半径 $1$ 的个数 $2,3,3,3,2,1$ 走到半径 $6$ 的 $5,5,5,5,6,2$，每人增加 $3,2,2,2,4,1$。相加是 $14$，对应七条新边的两端。原有四条长度为 $1$ 的边，$4+7=11$。$5+5+5+5+6+2=28$，等于 $11\times 2+6$。戊到六处是 $4,3,2,1,0,6$，最大是 $6$，个数 $6$。己只含戊和自己，个数 $2$。$2<3$，所以组号可以是 $0$，核心仍不是己。

组号 0 0 0 0 0 0

**11.** （1）定义里的个数包括自己。乙的邻居是甲和丙，加上自己是 $3$，正好够。只数别人就只剩 $2$，半径 $1$ 时乙不再是核心，链会断。（2）己的组号从 `-1` 变成 `0`。甲和戊从非核心变成核心，组号本来就是 `0`，没有换组。（3）第35讲的 $\dfrac{2}{3}$ 不重算。第56讲的两棵树不重算。第55讲的场心不重算。第58讲的轮廓系数先不算。库和实现会换，核心、密度可达、噪声不换。
