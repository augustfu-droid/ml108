## 核心理念：工具与模型会换，背后的数学思想不换

《墨点成星：机器学习一百零八讲》以**宋代山水的留白与暗房摄影的光影**，配合**纸笔全程手算推导 + Python / PyTorch 源码复现**，从一条直线、一个向量、一把矩阵的锁出发，一路讲透奇异值分解（SVD）、凸优化、梯度提升树、Transformer 注意力机制、扩散模型以及金融市场里的量化回测铁律。
